Build a support assistant answering from docs (RAG), calling tools in an agent loop, exposing the schema to coding agents over MCP. Requires `AI_API_KEY`. Retrieval and MCP run locally. Run from repo root.

## Resolve the backends

`Agent()` builds a tool-calling loop over shared `AI`. `RAG()` builds retrieval over `AI` + `VectorStore`:

```sh
AI_API_KEY=sk-... zever doctor --json | head -5
```

AI backend (`aianthropic.New` default) is wired in `internal/app/wiring.go`. Only the key comes from env.

## Index your docs

Ingest once, retrieve top-K per question. Chunking, batch embedding, upserting are one call:

```sh
# Conceptually: engine.Ingest(ctx, docs) then engine.Answer(ctx, query, 5)
# See core/rag/rag.go and the RAG section of the AI guide.
```

## Run the loop with tools

Register domain tools, then run. Unknown tools fail closed. Handler errors return as tool turns so the model self-corrects:

```sh
# Conceptually: agent.New(client, agent.Options{Model: "gpt-4o", Tools: tools})
# then loop.Run(ctx, messages). See core/agent/agent.go.
```

## Stream progress and fan out

Long runs stream deltas, tool calls, results as events. Independent calls in one step run concurrently with `MaxParallel`. Results keep order:

```sh
# Conceptually: loop.RunStream(ctx, messages) then range over events.
# See core/agent/stream.go.
```

## Serve your API as agent tools

Compile with the `mcp` backend: one manifest per module (`generated/mcp/<module>/mcp.json`), merged `generated/mcp/mcp.json`, runnable stdio server with stubs (`generated/mcp/<module>/mcpserver/main.go`):

```sh
zever compile schema/app.zen --backend=mcp --out ./generated
go run ./generated/mcp/<module>/mcpserver
```

Separately, `go run ./tools/zever-mcp` gives coding agents the compiler as tools (`zever_compile`, `zever_schema`, `zever_explain`).

## Score answers with evals

Pin quality with a dataset and scorers before shipping prompt changes:

```sh
# Conceptually: eval.RunSuite(ctx, run, cases, eval.ContainsScorer).
# See core/eval/eval.go.
```

## What you built

- `container.Agent()` / `container.RAG()` over shared backends
- `core/agent`: run, stream, parallel fan-out, sub-agent tools
- `core/rag`: ingest, retrieve, hybrid retrieval, grounded answers
- `dsl/backend/mcp` manifests + generated stdio server. `tools/zever-mcp` compiler tools
- `core/eval` datasets and scorers

<details>
<summary>`Agent()` fails with an auth error</summary>

No API key. Loop needs a real backend. Fix: set `AI_API_KEY`. Retrieval-only paths work with any embedder.
</details>

<details>
<summary>Hybrid retrieval returns nothing</summary>

Hybrid engines index chunks into the keyword backend on ingest. Fix: re-ingest after switching `rag.New` → `rag.NewHybrid`.
</details>
