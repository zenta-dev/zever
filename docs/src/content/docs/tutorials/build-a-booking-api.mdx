Run `examples/bookings` (hosts list spaces, guests book them) in ~15 minutes. Requires Go 1.27+, `zever` CLI, repo clone. Run all commands from `examples/bookings/`:

```sh
cd examples/bookings
```

## Read the schema

Domain in one file: `User`, `Space`, `Booking`, `Review` entities, `BookingService` RPCs, `SendConfirmation`/`SendReminder` jobs, `Reminder` cron. See [Zen syntax](../../reference/zen-syntax/).

```sh
cat schema/bookings.zen
```

## Migrate the database

Generated code under `generated/` is committed. Never hand-edit, regenerate with `zever compile`:

```sh
zever db migrate --adapter=sqlite --dsn=data/bookings.db schema/bookings.zen
```

Checkpoint:

```text
OK applied 8 statement(s) via sqlite
```

Run `zever doctor` from here. Elsewhere its db check reports a path miss.

## Seed demo data

Idempotent:

```sh
go run ./db/seed
```

Checkpoint:

```text
{"time":"...","level":"INFO","msg":"seed complete"}
```

Creates `host@example.com`, `guest@example.com`, two spaces, one confirmed booking.

## Set a JWT secret and serve

Fails closed when `AUTH_JWT_SECRET` is missing or under 32 bytes ([Configuration](../../guides/operate/configuration/)). Export one (never commit a real one):

```sh
export AUTH_JWT_SECRET=dev-only-secret-at-least-32-bytes-long
go run ./cmd/server
```

Checkpoint (`-addr` changes port):

```text
{"time":"...","level":"INFO","msg":"http server listening","addr":":8080"}
```

<Aside type="caution" title="Fail-closed secret">
Missing/short secret exits at startup naming the field instead of serving insecurely.
</Aside>

## Start the worker

Second terminal, same secret (jobs plus scheduler):

```sh
export AUTH_JWT_SECRET=dev-only-secret-at-least-32-bytes-long
go run ./cmd/worker
```

Checkpoint:

```text
{"time":"...","level":"INFO","msg":"worker started","jobs":2,"schedules":1}
```

Consumes `default` and `low` queues. Fires `Reminder` cron (`0 9 * * *`). `SendConfirmation` sends mail receipt (`mailer/log`), guest push (`notification/log`), `booking.created` webhook when configured (skipped quietly when none. App README lists `BOOKINGS_WEBHOOK_*`). `SendReminder` notifies guests of confirmed bookings starting within 7 days.

## Call the API

Register:

```sh
curl -s -X POST localhost:8080/api/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"correct horse battery staple"}'
```

```text
{"id":"01J00000000000000000000000","email":"you@example.com"}
```

Log in (response JWT covers every other route):

```sh
curl -s -X POST localhost:8080/api/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"correct horse battery staple"}'
```

```text
{"token":"eyJhbGciOi..."}
```

List spaces, then book:

```sh
TOKEN=... # from the login response

curl -s localhost:8080/api/spaces -H "Authorization: Bearer $TOKEN"
```

```text
[{"id":"...","host_id":"...","title":"...","price_cents":...},{"id":"...","host_id":"...","title":"..."}]
```

```sh
curl -s -X POST localhost:8080/api/bookings \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"space_id":"...","start_date":"2026-01-01","end_date":"2026-01-03"}'
```

```text
{"booking":{"id":"...","space_id":"...","status":"confirmed",...},"message":"...","payment_id":"..."}
```

Response is HTTP 201. Repeating it replays the first result with HTTP 200 (idempotent replay).

## Trace one booking through the stack

1. `auth`: bearer JWT verified, attached to context.
2. `ratelimit`: per-guest quota checked. Over quota → 429.
3. `idempotency`: retried POST with same `Idempotency-Key` header, `idempotency_key` body field, or same guest/space/dates replays first result.
4. `lock`: space date range held. Overlap → 409 `dates already booked`.
5. `payment`: stub charge (no real funds), booking saved as `confirmed`.
6. `queue`: `bookings.confirm` pushed. `memory` queue is per process, so the separate worker misses it. Set `queue` to a shared adapter (e.g. `redis`) in both processes to hand work across.

## Understand the doctor failures

```sh
zever doctor
```

Expect 30 OK, 4 FAIL: `ai` (no API key), `auth` (no JWT secret), `geo` (missing fixture), `i18n` (missing embed FS). Deliberate zero-infra gaps, listed in app `README.md`.

## What you built

One request touched auth, rate limiting, idempotency, locking, payment, ORM, queue. The worker ran job and schedule handlers.

<details>
<summary>Troubleshooting</summary>

**Server exits naming `AUTH_JWT_SECRET`.** Secret missing or shorter than 32 bytes, export a longer dev-only value.

**`curl` 401 on `/api/spaces`.** Missing `Authorization: Bearer $TOKEN`, or token from a different secret. Log in again in the terminal with the secret.

**Booking 429/409.** 429: rate limit, wait out window. 409: dates overlap a booking or one is in progress.
</details>
