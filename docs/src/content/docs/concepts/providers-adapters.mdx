Each backend concern is one small interface with several adapters, resolved only by the container: swaps stay wiring-plus-env edits, never handler rewrites.

## The mental model

| Role | Rule |
|---|---|
| Interface | Stays small: never add methods, add an interface instead. |
| Adapter | One subdirectory per backend, `Provide`-bound to a `Ref`. |
| Container | Sole resolver: construction, caching, retry, close. |
| Config | Feeds options only. No adapter key, the backend is the wired constructor. |

In handlers:

```go
conn, err := c.DB() // the wired db instance, built once and cached
```

Each battery is one interface plus typed `Options` and a `DefaultRef`. Adapters are plain constructors bound by `container.Provide`:

```go
// Package db: one small interface.
type DB interface {
	Query(ctx context.Context, query string, args ...any) (Rows, error)
	Exec(ctx context.Context, query string, args ...any) (int64, error)
	Ping(ctx context.Context) error
	Close(ctx context.Context) error
	Dialect() string
}

// Adapter sqlite lives in its own module; postgres lives elsewhere.
// Import the one you ship and bind it with container.Provide in
// internal/app/wiring.go; app code holds no globals.
import dbsqlite "github.com/zenta-dev/zever/adapters/db/sqlite"

var DB = db.DefaultRef()

func Providers() []container.Provider {
	return []container.Provider{
		container.Provide(DB, dbsqlite.New),
	}
}
```

## Swap an adapter

Dev stays zero-infra. Production changes wiring and env:

```sh
zever add cache/redis
```

That edits `internal/app/wiring.go` (the `cache` `Ref` now binds redis. `.env.example` gains its keys). The env carries that adapter's options:

```sh
DB_DSN=postgres://app:secret@db:5432/app
DB_MAX_CONNS=20
CACHE_ADDR=redis:6379
```

Env names carry no prefix. The default instance reads `<SERVICE>_<FIELD>` (`DB_MAX_CONNS=20`), a named instance reads `<SERVICE>__<NAME>__<FIELD>` (`DB__PRIMARY__MAX_CONNS=20`) and only resolves through a matching named Ref such as `db.Ref("primary")`. Each instance opens the adapter its `container.Provide` call binds while handlers keep calling `c.DB()` and `c.Cache()`. `zever doctor` reports per-service health. Under zero-infra defaults the bookings example documents expected FAILs (missing API key, JWT secret, cities file, embed FS): config gaps, not bugs.

Placeholders stay `?` on both `db` drivers (postgres rewrites to `$n` before pgx). Route params read through `router.Param`. Two known gaps:

- `MinConns` is a pool minimum on postgres but `SetMaxIdleConns` on sqlite.
- Regex route constraints exist on fiber but not stdhttp.

## Adapter matrix

Excerpt. The full table covers all 37 services, each zero-infra by default except `ai`: [adapters matrix](../../reference/adapters-matrix/).

| Service | Adapters | Default |
|---|---|---|
| `db` | `sqlite`, `postgres` | `sqlite` |
| `cache` | `memory`, `redis`, `db` | `memory` |
| `queue` | `memory`, `redis`, `db` | `memory` |
| `router` | `fiber`, `stdhttp` | `stdhttp` |
| `auth` | `jwt`, `session`, `oidc` | `jwt` |
| `session` | `memory`, `redis`, `db` | `memory` |
| `storage` | `local`, `s3`, `r2` | `local` |
| `search` | `db`, `meilisearch` | `db` |
| `vectorstore` | `db`, `qdrant` | `db` |
| `payment` / `billing` | `stub`, `stripe`, `paddle` | `stub` |
| `log` | `noop`, `zerolog`, `slog`, `pretty` | `slog` |
| `secrets` | `env`, `vault` | `env` with `ZEVER` prefix |

`search`, `vectorstore`, and `workflow` use `db` as their DB-backed adapter, so the DSN picks the backend: empty or sqlite selects embedded SQLite, a postgres URL selects PostgreSQL. The old `postgres`/`sqlite`/`pgvector` names for those services are gone.

## Add a new adapter

1. Implement the interface exactly: no extra exported methods on the facade.
2. Parse options with typed readers. Return `InvalidOptionsError` on unparsable values.
3. Never log raw option maps. Redact via `Redact` / `RedactedServices`.
4. Make shutdown cheap and idempotent: implement `Close(ctx)`, `Close()`, or `Stop()` for the container's probing.
5. Keep tests hermetic (sqlite `:memory:`, in-memory fakes). Gate live tests behind env such as `POSTGRES_DSN`.

Unexported adapters are named `driver` (receiver `d`). Timeouts are `time.Duration` with `Default*Timeout` constants.

## Design decisions and trade-offs

- **Close shape is contractual.** See [Container](../container/#close-services-in-order) for each adapter's signature.
- **Fail closed.** Unsupported ORM features return `dialect.ErrUnsupportedByDialect` (prefixed `orm:`), strict config rejects unknown keys at load, redaction masks secrets everywhere.

## Troubleshooting

<details>
<summary>The swap changes nothing at runtime</summary>

The wiring still binds the old adapter. Check the `container.Provide` line in `internal/app/wiring.go` and rebuild. Drop any leftover `*_ADAPTER` key from `.env`.
</details>

<details>
<summary>An accessor fails with `NotWiredError`</summary>

No `container.Provide` entry covers the service. Add the import and `Provide` line in `internal/app/wiring.go` and rebuild. Drop leftover `*_ADAPTER` keys.
</details>

<details>
<summary>A handler sees different SQL on postgres</summary>

Keep writing `?`. The postgres driver rewrites to `$n` before pgx.
</details>

<details>
<summary>A fiber-only route constraint breaks stdhttp</summary>

Regex constraints exist on fiber only. Restructure the route with constructs both drivers share, or pin `fiber`.
</details>

<details>
<summary>A live adapter test fails in CI</summary>

The test needs a real backend with no DSN set. Gate it behind env (`POSTGRES_DSN='postgres://user:pass@localhost:5432/test?sslmode=disable'`).
</details>
