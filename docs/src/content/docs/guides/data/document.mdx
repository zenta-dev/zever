`document.Document` renders a source to PDF/image with one `Render` call: typed `OutputFormat` (`pdf`, `png`, `jpg`), `Quality` bounded 0 to 100. Callers never learn whether LaTeX or a remote API did the work.

## Quick start

- `local` (default, `adapters/document/local`): HTML in headless Chrome.
- `latex`: shells out to a fixed, configured compiler, use for `.tex` sources.
- `remote`: sends the job to a rendering API. Needs `endpoint` (https, or http with `allow_insecure: true`), non-empty `api_key` goes as bearer token. Requests dial only globally routable addresses, never follow redirects, a local sidecar needs `allow_private: true` (logs one line at startup).

```sh
DOCUMENT_QUALITY=80
DOCUMENT_DPI=150
DOCUMENT_TMP_DIR=/tmp/zever-doc
DOCUMENT_MAX_OUTPUT_BYTES=67108864
DOCUMENT_TIMEOUT=30s
```

`quality` 0 to 100 (`Validate` rejects others, `ClampQuality` clamps user input first), `dpi`, `max_output_bytes` (default 64 MiB), `timeout` must be ≥ 0. Durations are nanoseconds, env accepts `30s`. `latex_command`, `latex_pdf_to_ppm` (defaults `pdflatex`, `pdftoppm`) are config-only, never interpolated from content. `latex_runs` bounds compiler passes. `remote` `endpoint` must be absolute URL with scheme + host (`allow_insecure` permits http). See [document options](../../../reference/config/#document).

## Render a document

Register the adapter first (the container wires nothing). `Document()` resolves lazily, caches, retries.

```go title="main.go" check
package main

import (
	"context"
	"fmt"
	"os"

	documentlocal "github.com/zenta-dev/zever/adapters/document/local"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/document"
)

func main() {
	ctx := context.Background()
	c := container.New(config.Default(), container.Provide(document.DefaultRef(), documentlocal.New))
	defer c.Close(ctx)

	d, err := c.Document()
	if err != nil {
		panic(err)
	}
	out, err := d.Render(ctx, []byte(`hello`), document.FormatPDF)
	if err != nil {
		panic(err) // out is nil on error, never a partial file
	}
	if err := os.WriteFile("/tmp/hello.pdf", out, 0o600); err != nil {
		panic(err)
	}
	fmt.Println("bytes:", len(out))
}
```

```text
bytes: 1240
```

Byte count varies by adapter/source. Check the error before writing to disk.

## Production checklist

- Cap sources (10 MiB default) and output (64 MiB default), raise only with a measured reason.
- `latex` never interpolates caller commands, so content cannot reach a shell. Lock down `tmp_dir`.
- LaTeX runs hardened: fresh temp dir as `cwd`, `-no-shell-escape`, minimal env (only `PATH`, `HOME`, `TEXMF*`, all else dropped). `openout_any=p` blocks `\openout` outside the tree, `openin_any=p` restricts `\input` where still honored. On timeout the whole process group is killed.
- Treat LaTeX as code with untrusted input: set `latex_sandbox: required` with [bubblewrap](https://github.com/containers/bubblewrap) (`bwrap`). Also run unprivileged, keep `tmp_dir` on a dedicated mount, set `timeout` + `max_output_bytes` (size-checked before reading into memory). No OS sandbox on Windows (use container/VM), timeout kills only the direct TeX process.
- Bound renders with `timeout`, clean temp artifacts on error paths.
- `api_key` never logged, `endpoint` validated before the first request.

<details>
<summary>LaTeX sandbox and source pre-scan details</summary>

TeX runs with `--unshare-all` (no network/IPC/PID visibility), `--die-with-parent`, read-only system/TeX trees, per-render temp dir as the only writable path (`/etc`, `/home`, app files absent, so `\input{/etc/hostname}` fails). `latex_sandbox`: `auto` (default: use bwrap when it works, else one warning, continue unsandboxed), `required` (fail at open when bwrap is missing/unusable, e.g. unprivileged userns disabled, containers usually need a seccomp/userns allowance), `off`. A pre-scan rejects `\input`, `\include`, `\openin`, `\openout`, `\verbatiminput` and similar with absolute/`..`/`~`/piped paths, `\write18`, shell-escape packages (`shellesc`, `minted`, `pythontex`, …) with `ErrUnsafeSource`. Best effort only (misses `\csname`/`\catcode` tricks), never a substitute for the OS sandbox. `latex_allow_unsafe_source: true` disables it for fully trusted sources. Since TeX Live 2026 `openin_any` is a documented upstream no-op, so the engine alone cannot stop `\input{/etc/passwd}`, these controls cover that gap.
</details>

## Troubleshooting

<details>
<summary>`Render` returns nil bytes and an error</summary>

Contract: no partial files. Inspect the error, skip writing, check the 10 MiB source cap.
</details>

<details>
<summary>LaTeX renders fail with "command not found"</summary>

`latex_command`/`latex_pdf_to_ppm` not on `PATH` (or not absolute). Install them or use `remote`.
</details>

<details>
<summary>Remote renders fail validation before any request</summary>

`endpoint` not absolute URL with scheme + host, or negative `timeout`. Correct config, nothing was sent.
</details>
