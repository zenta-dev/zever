`cache.Cache` stores slow values by stable key with a TTL. Entries expire, evict under `max_entries`, and `memory` entries vanish on restart.

## Quick start

`memory` for one process (default), `redis` to share.

<Tabs>
  <TabItem label="memory">
```sh
CACHE_SWEEP_INTERVAL=1m
CACHE_MAX_ENTRIES=10000
```
  </TabItem>
  <TabItem label="redis">
```sh
CACHE_ADDR=localhost:6379
CACHE_POOL_SIZE=20
CACHE_MIN_IDLE_CONNS=2
```
  </TabItem>
</Tabs>

Durations use Go strings (`"1m"`). Env matching ignores case and `_`. Unknown keys under `CACHE_` fail with a did-you-mean hint, unknown service heads are ignored. See [cache options](../../../reference/config/#cache).

## Cache a value with a TTL

Wire via `container.Provide`, `Cache()` is lazy, cached, retried (`container.New(nil)` is valid).

```go title="main.go" check
package main

import (
	"context"
	"fmt"
	"time"

	cachememory "github.com/zenta-dev/zever/adapters/cache/memory"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/cache"
)

func main() {
	ctx := context.Background()
	c := container.New(config.Default(), container.Provide(cache.DefaultRef(), cachememory.New))
	defer c.Close(ctx)

	ch, err := c.Cache()
	if err != nil {
		panic(err)
	}
	if err := ch.Set(ctx, "space:42", []byte("loft"), 5*time.Minute); err != nil {
		panic(err)
	}
	raw, err := ch.Get(ctx, "space:42")
	if err != nil {
		panic(err)
	}
	fmt.Println(string(raw))
}
```

```text
loft
```

Missing keys wrap `cache.ErrNotFound`. Also: `SetIfAbsent`, `Delete`, `Increment`, `Decrement`, `Exists`.

## Cache structs with typed helpers

`cache.NewTyped` wraps any backend with a codec, skipping manual JSON.

```go title="typed.go"
import (
	"github.com/zenta-dev/zever/core/cache"
	"github.com/zenta-dev/zever/shared/codec"
)

type SpaceCard struct {
	Title      string `json:"title"`
	PriceCents int64  `json:"price_cents"`
}

typed := cache.NewTyped[string, SpaceCard](ch, codec.JSONCodec[SpaceCard]{})
err := typed.Set(ctx, "space:card:42", SpaceCard{Title: "Loft", PriceCents: 12000}, 5*time.Minute)
card, err := typed.Get(ctx, "space:card:42")
fmt.Println(card.Title, card.PriceCents) // Loft 12000
```

Keys accept strings or numerics. `cache.CompareAndSwapCache` backends add `CompareAndDelete`/`CompareAndExtend`, acting only on value match.

## Choose an adapter

| Adapter | Package | Notes |
|---|---|---|
| `memory` | `adapters/cache/memory` | Default, process-local, closes instantly |
| `redis` | `adapters/cache/redis` | Shared, pool-backed |
| `db` | `adapters/cache/db` | Over `shared/kvstore`. Empty `dsn` uses in-memory sqlite, postgres URL uses postgres. Counters are read-modify-write, not linearizable under contention |

One interface. `db` shares one pool per DSN unless `dedicated_pool: true`. Size `max_entries` (memory default 1000, sweep 1m), on Redis set `pool_size`, `min_idle_conns`, `pool_timeout`, `max_conn_idle_time`, `max_conn_lifetime`. Keep TTLs explicit and short, version keys on type changes (`space:card:v2:42`). See the [adapters matrix](../../../reference/adapters-matrix/).

## Troubleshooting

<details>
<summary>Typed `Get` returns decode errors after a deploy</summary>

Stale shape. Bump key version or `Delete` old prefix.
</details>

<details>
<summary>Instance A writes, instance B misses</summary>

`memory` across instances. Wire `redis` with shared `CACHE_ADDR`, confirm via `RedactedServices`.
</details>

<details>
<summary>Unknown key under `CACHE_` fails startup</summary>

Config is env-only. Unknown keys under `CACHE_` fail with a did-you-mean hint, unknown service heads are ignored, durations use Go strings such as `"1m"`.
</details>

<details>
<summary>Shutdown hangs or logs pool timeouts</summary>

No close deadline. Pass `context.WithTimeout` to `c.Close(ctx)`.
</details>
