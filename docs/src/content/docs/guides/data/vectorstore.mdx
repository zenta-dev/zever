`vectorstore.VectorStore` ranks embeddings by cosine similarity. Pair with `ai.Embed` to embed, upsert, and query.

## Quick start

`db` serves two backends under one name: empty `dsn` → embedded sqlite, postgres URL → pgvector. `qdrant` is the purpose-built vector DB at scale. Code does not change.

<Tabs>
  <TabItem label="db">
```sh
VECTORSTORE_DIMENSION=1536
VECTORSTORE_DSN=:memory:
```
  </TabItem>
  <TabItem label="qdrant">
```sh
VECTORSTORE_URL=http://localhost:6333
VECTORSTORE_ALLOW_INSECURE=true
VECTORSTORE_API_KEY=dev-only-key
```
  </TabItem>
</Tabs>

Backend is wired in code. `dimension` defaults to 1536 (OpenAI text-embedding-3-small) on pgvector (fixes column size), Qdrant checks it only when set, sqlite learns it from the first write. Mismatches → `vectorstore.ErrDimensionMismatch`, negatives rejected. `url` needs scheme + host. `dedicated_pool: true` opts out of sharing. Adapter is `db`: sqlite path → SQLite, postgres URL → pgvector. See [vectorstore options](../../../reference/config/#vectorstore).

## Upsert and query vectors

Wire with `container.Provide` in `internal/app/wiring.go`. `VectorStore()` is lazy, cached, retried.

```go title="main.go" check
package main

import (
	"context"
	"fmt"

	vectorstoredb "github.com/zenta-dev/zever/adapters/vectorstore/db"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/vectorstore"
)

func main() {
	ctx := context.Background()
	c := container.New(config.Default(), container.Provide(vectorstore.DefaultRef(), vectorstoredb.New))
	defer c.Close(ctx)

	vs, err := c.VectorStore()
	if err != nil {
		panic(err)
	}
	err = vs.UpsertBatch(ctx, []vectorstore.Vector{
		{ID: "doc-1", Embedding: []float32{1, 0, 0}},
		{ID: "doc-2", Embedding: []float32{0, 1, 0}},
	})
	if err != nil {
		panic(err)
	}
	matches, err := vs.Query(ctx, []float32{1, 0, 0}, 2)
	if err != nil {
		panic(err)
	}
	for _, m := range matches {
		fmt.Println("match:", m.ID, m.Score)
	}
}
```

```text
match: doc-1 1
match: doc-2 0
```

## Production checklist

- `Query` is cosine similarity only. For hybrid ranking, combine with [search](../search/).
- `topK <= 0` defaults to 10, paginate explicitly for large sets.
- Use `UpsertBatch` for batches, looping `Upsert` costs one round trip per vector.
- Empty embeddings rejected before I/O. `api_key` never logged.

See the [adapters matrix](../../../reference/adapters-matrix/) for `db` and `qdrant`.

## Troubleshooting

<details>
<summary>Query results look random</summary>

Vectors from a different model than stored, or wrong `dimension`. Align config with the model and re-upsert, `ErrDimensionMismatch` means sizes differ.
</details>

<details>
<summary>Writes are slow at scale</summary>

Looping `Upsert`. Use `UpsertBatch`.
</details>

<details>
<summary>`qdrant` fails to resolve</summary>

`url` lacks scheme/host or is not https. Check `VECTORSTORE_URL`, set `VECTORSTORE_ALLOW_INSECURE=true` for plain-http local servers.
</details>
