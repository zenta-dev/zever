`cdn.CDN` invalidates provider edge caches so visitors see fresh files. `noop` discards purges (zero-infra default), `cloudflare` calls the Cloudflare purge API.

## Quick start

`noop` for local development (default, no infra), `cloudflare` when files sit at Cloudflare's edge.

Backend is wired in code, not env. `cloudflare` requires `api_token` + `zone_id`, `base_url` defaults to `https://api.cloudflare.com/client/v4`. Tokens are never logged (display via `config.RedactedServices`). See [cdn options](../../../reference/config/#cdn).

## Purge content

Wire with `container.Provide`, then resolve from the container (lazy, cached, retries, `container.New(nil)` is valid).

```go title="main.go" check
package main

import (
	"context"

	cdncloudflare "github.com/zenta-dev/zever/adapters/cdn/cloudflare"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/cdn"
)

func main() {
	ctx := context.Background()
	c := container.New(config.Default(), container.Provide(cdn.DefaultRef(), cdncloudflare.New))
	defer c.Close(ctx)

	cd, err := c.CDN()
	if err != nil {
		panic(err)
	}

	if err := cd.Purge(ctx, cdn.PurgeRequest{
		URLs: []string{"https://example.com/assets/app.js"},
	}); err != nil {
		panic(err)
	}
	if err := cd.Purge(ctx, cdn.PurgeRequest{
		Tags: []string{"static", "v2"},
	}); err != nil {
		panic(err)
	}
	if err := cd.Purge(ctx, cdn.PurgeRequest{All: true}); err != nil {
		panic(err)
	}
}
```

Zero `PurgeRequest` is a no-op returning an error. `All: true` purges the whole zone. Also: `Close(ctx)`, `Name()`.

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `api_token` | string | `""` | Cloudflare API token. Required. Never logged |
| `zone_id` | string | `""` | Cloudflare zone identifier. Required |
| `base_url` | string | `https://api.cloudflare.com/client/v4` | API endpoint override |

No retry logic: provider errors return to the caller. See [cdn options](../../../reference/config/#cdn).

## Choose an adapter

| Adapter | Package | Notes |
|---|---|---|
| `noop` | `adapters/cdn/noop` | Default, discards purges, closes instantly |
| `cloudflare` | `adapters/cdn/cloudflare` | Calls the purge API via `cloudflare-go/v7`, no retries |

One interface, so switching is config-only. See the [adapters matrix](../../../reference/adapters-matrix/).

## Troubleshooting

<details>
<summary>`Purge` returns `cdn: empty purge request`</summary>

Zero `PurgeRequest` (no URLs, tags, or `All`). Set at least one field.
</details>

<details>
<summary>`cloudflare: option "api_token" is required`</summary>

Adapter selected without credentials. Set `api_token` + `zone_id` (`CDN_API_TOKEN`, `CDN_ZONE_ID`).
</details>

<details>
<summary>Purge succeeds but visitors see stale content</summary>

URL/tag does not match the cached edge entry. Purge by exact URL/tag, or `All: true`.
</details>
