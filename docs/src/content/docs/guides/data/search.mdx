`search.Search` indexes documents and runs ranked queries with filters and paging, the query surface stays constant across backends. For user-typed queries over spaces, bookings, or help articles, embeddings belong in the [vector store](../vectorstore/).

## Quick start

`db` with sqlite path or `:memory:` is embedded FTS (default, tests/small corpora), a postgres URL reuses your relational DB. `meilisearch` is a dedicated cluster (best ranking/latency).

<Tabs>
  <TabItem label="db">
```sh
SEARCH_DSN=./data/search.db
```
  </TabItem>
  <TabItem label="meilisearch">
```sh
SEARCH_HOST=http://localhost:7700
SEARCH_API_KEY=dev-only-key
SEARCH_ALLOW_INSECURE=true
```
  </TabItem>
</Tabs>

`host` is the Meilisearch URL (scheme + host), `dsn` is a postgres URL or sqlite path. `dedicated_pool: true` opts out of pool sharing. `searchdb.New` reads the DSN to pick the backend: sqlite path → embedded FTS5, postgres URL → tsvector/GIN. Env keys follow `<SERVICE>_<FIELD>` (e.g. `SEARCH_DSN`). Keep secrets in files/env, never committed plaintext. See [search options](../../../reference/config/#search).

## Index and query documents

Container wires nothing, register `db` first. Batch indexing validates all documents before writing any.

```go title="main.go" check
package main

import (
	"context"
	"fmt"

	searchdb "github.com/zenta-dev/zever/adapters/search/db"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/search"
	"github.com/zenta-dev/zever/shared/dbconn"
)

func main() {
	ctx := context.Background()
	c := container.New(config.Default(), container.Provide(search.DefaultRef(), func(o search.Options) (search.Search, error) {
		poolOpts := dbconn.SplitDSN(o.DSN)
		return searchdb.New(searchdb.Options{Options: poolOpts})
	}))
	defer c.Close(ctx)

	s, err := c.Search()
	if err != nil {
		panic(err)
	}
	err = s.IndexBatch(ctx, []search.Document{
		{ID: "space-1", Index: "spaces", Content: "sunny loft downtown"},
	})
	if err != nil {
		panic(err)
	}
	res, err := s.Search(ctx, "loft", search.QueryOptions{
		Limit:   10,
		Filters: map[string]string{"index": "spaces"},
	})
	if err != nil {
		panic(err)
	}
	fmt.Println("total", res.Total, res.Hits[0].ID)
}
```

```text
total 1 space-1
```

`Search()` is lazy, retried, `search.Open(search.DB, opts)` opens directly. Scores vary by backend, assert it in tests, not exact scores. `Total` ignores `Limit`/`Offset`, so `len(res.Hits)` can be smaller. `Limit <= 0` → 10. Only `index` filter honored: `db` searches all without it, `meilisearch` requires it (`ErrIndexRequired`).

## Choose an adapter

| Adapter | Package | Notes |
|---|---|---|
| `db` | `search/db` | Default. sqlite path / `:memory:`, or postgres URL |
| `meilisearch` | `search/meilisearch` | External cluster, needs `host` (`api_key` if server has master key) |

All serve `Index`, `IndexBatch`, `Delete`, `Search`, `Close`. Promoting `db` → `meilisearch` is config + reindex. Search closes after scheduler/job, before leaf cache/queue. See the [adapters matrix](../../../reference/adapters-matrix/).

## Troubleshooting

<details>
<summary>`host must be a valid url with scheme and host`</summary>

Bare `localhost:7700`. Use `http://localhost:7700` (+ `allow_insecure: true` for plain http).
</details>

<details>
<summary>Results mix spaces with help articles</summary>

`Filters["index"]` missing/misspelled. Always pass `map[string]string{"index": "spaces"}`.
</details>

<details>
<summary>`len(hits)` smaller than `Total`</summary>

Paging by design. Loop with `Offset`, show `Total` as the count.
</details>

<details>
<summary>sqlite works locally but postgres fails in staging</summary>

`dsn` holds a sqlite path against a postgres target, or the role lacks index tables. Use path for sqlite, URL for postgres, migrate index tables, then reindex.
</details>
