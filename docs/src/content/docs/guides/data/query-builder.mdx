`orm` is a generics-typed SQL builder over `db.DB`. Use raw `conn.Exec` only for shapes the DSL cannot express (e.g. FTS5 DDL).

## Quick start

Resolve `db` once, dialect resolves per call from `conn.Dialect()`.

```sh
DB_PATH=app.db
```

```go title="main.go"
c := container.New(config.Default())
conn, err := c.DB()
if err != nil {
    return err
}
defer c.Close(ctx)
```

`config.Default()` is sqlite (no server), postgres needs `dsn` ([db options](../../../reference/config/#db)).

## Define tables and models

Models implement `Scan(orm.Row) error`, `orm.From` infers the type.

```go title="models.go"
import "github.com/zenta-dev/zever/orm"

type User struct {
    ID   int64
    Name string
}

func (u *User) Scan(row orm.Row) error { return row.Scan(&u.ID, &u.Name) }

var (
    Users    = orm.NewTable[User]("users", []string{"id", "name"})
    UserID   = orm.NewColumn[User, int64]("users", "id")
    UserName = orm.NewColumn[User, string]("users", "name")
)
```

`orm.NewNullableColumn` adds `IsNull`, `IsNotNull`, `SetValue`, `SetNull`.

## Select, filter, and read rows

Chain `Where`, `OrderBy` (`Asc`/`Desc`), `Limit`, `Offset`, `Columns`, `Distinct`, `DistinctOn`, then read.

```go
users, err := orm.From(Users).
    Where(UserName.Eq("alice")).
    OrderBy(UserID.Desc()).
    Limit(10).
    All(ctx, conn) // []*User
```

Reads: `All`, `First` (+ `ok`), `FirstOrErr` (`db.ErrNotFound`), `Count`, `Exists`, `Stream` (`iter.Seq2`, constant memory, holds connection until finished).

## Join, group, and compose queries

Joins run over a `Relation`, returning typed rows.

```go
rel := orm.NewRelation[User, Booking]("id", "user_id", Bookings)
inner := orm.JoinOn(orm.From(Users), rel, orm.InnerJoin)
left := orm.LeftJoinOn(orm.From(Users), rel)

name, err := orm.NewCTEName("active_users")
cte := orm.With(name, orm.From(Users).Where(Active.Eq(true)))
```

- Joins: `JoinOn`, `LeftJoinOn`, `RightJoinOn`, `FullJoinOn`, `JoinOn3` family, lateral variants.
- CTEs: `With`, `WithRecursive`, `WithJoin`, `WithGrouped`, `NewCTEName`, `CTETable`.
- Windows: `RowNumber`, `Rank`, `DenseRank`, `Lead`, `Lag`, `NTile`, `CountOver`, `SumOver`, `AvgOver`, `MinOver`, `MaxOver`, frame bounds.
- Sets: `Union`, `UnionAll`, `Intersect`, `Except`, inspection: `Explain`, `ExplainAnalyze`.
- `orm.Preload(ctx, conn, parents, childFK, childBase, parentID, childFKOf)` loads children without N+1, returning `[]orm.ParentWithChildren`.

## Insert, update, and delete

`Values`/`Set` take `orm.Set(column, value)`, `Update`/`Delete` return affected rows.

```go
err := orm.InsertInto(Users).Values(orm.Set(UserName, "alice")).Exec(ctx, conn)

n, err := orm.UpdateTable(Users).Set(orm.Set(UserName, "bob")).Where(UserID.Eq(1)).Exec(ctx, conn)

n, err = orm.DeleteFrom(Users).Where(UserID.Eq(1)).Exec(ctx, conn)
```

Upsert via `OnConflict(cols...).DoNothing()` / `.DoUpdate(sets...)`, merge via `orm.MergeInto(table)`, fetch rows in one round trip with `Returning` + `ExecReturning` where supported.

## Run transactions and retries

`db.WithTx` commits on success, rolls back on error/panic (re-panics), nesting returns `db.ErrNestedTx`. `orm.WithNestedTx` for savepoints, `orm.RetryTx` for serialization retries.

```go
err = db.WithTx(ctx, conn, &db.TxOptions{Isolation: db.Serializable},
    func(ctx context.Context, tx db.Tx) error {
        _, err := orm.UpdateTable(Users).Set(orm.Set(UserName, "bob")).Where(UserID.Eq(1)).Exec(ctx, tx)
        return err
    })

err = orm.RetryTx(ctx, conn, orm.RetryOptions{MaxAttempts: 3}, func(ctx context.Context, tx db.Tx) error {
    return transfer(ctx, tx)
})
```

`RetryOptions`: 3 attempts, 10ms linear backoff. Savepoints must match `[_A-Za-z][_A-Za-z0-9]*`.

## Paginate results

Offset pages are 1-based (`page < 1` / `size < 1` error), keyset pages stay correct when rows change.

```go
q, err := orm.OffsetPage(orm.From(Users).OrderBy(UserID.Asc()), 2, 25) // LIMIT 25 OFFSET 25
total, err := orm.From(Users).Count(ctx, conn)

key := orm.NewCursorKey(UserID, lastSeenID)
next := orm.NextPage(orm.From(Users).OrderBy(key.OrderTerm()).Limit(25), key)
token, err := key.Encode()                      // opaque page token
back, ok, err := orm.DecodeCursor(token, UserID)
pred, err := orm.AfterTuple(cols, vals, false)  // multi-column keyset
```

Keyset predicate must mirror `OrderBy` exactly (tie-breaker included) or pages skip/duplicate. See `go run ./examples/pagination/cmd/app`.

## Lock rows, query JSON, and search text

- Locks: `ForUpdate`, `ForShare`, `ForNoKeyUpdate`, `ForKeyShare`, `ForUpdateOf`, then `NoWait`/`SkipLocked`.
- JSON: TEXT column as `orm.JSONText`, predicates from `orm/json/sqlite` plus a postgres twin over jsonb.
- FTS: `orm/fts/sqlite` (`Match`, `Rank`) plus postgres twin over `tsvector`. Query text is always bound, create the FTS5 table with raw DDL in a migration.
- Examples: `./examples/fts/cmd/app`, `./examples/json_query/cmd/app`, `./examples/recursive_cte/cmd/app`.

## Handle dialect differences

Unsupported features fail closed with `dialect.ErrUnsupportedByDialect`: `DISTINCT ON` and strong locks are postgres-only, right/full joins and recursive CTEs gate by capability.

```go
rows, err := q.All(ctx, conn)
if errors.Is(err, dialect.ErrUnsupportedByDialect) {
    rows, err = portableQuery.All(ctx, conn)
}
```

Errors carry an `orm:` prefix, `errors.Is`-compatible. Test `:memory:` first, then live postgres: `POSTGRES_DSN='postgres://user:pass@localhost:5432/test?sslmode=disable' go test ./orm/...`. Pass `ctx` everywhere, display config via `config.RedactedServices`, close via `c.Close(ctx)`.

## Troubleshooting

<details>
<summary>`ErrUnsupportedByDialect` on sqlite</summary>

Postgres-only (`DISTINCT ON`, strong lock). Match with `errors.Is`, use portable form.
</details>

<details>
<summary>Keyset pages skip or duplicate rows</summary>

`AfterTuple` columns diverge from `OrderBy`. Keep `(price_cents ASC, id ASC)` identical, tie-breaker included.
</details>

<details>
<summary>`:memory:` tests see empty tables</summary>

Second pooled connection opened its own database. `:memory:` forces one connection, do not raise `max_conns`.
</details>
