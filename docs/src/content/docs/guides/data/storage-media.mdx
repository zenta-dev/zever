`storage.Storage` hands out presigned upload and download URLs for opaque objects such as receipts, photos, and exports, and gates access with one policy. `media` is the pipeline on top: upload, probe, transform, and serve, covered in [Media processing](../media/).

## Quick start

Pick `local` for a single instance. It writes under `root`, needs no infra, and is the default. Pick `s3` or `r2` once more than one instance must see the same files.

<Tabs>
  <TabItem label="local">
```yaml title="zever.yaml"
storage:
  adapter: local
  options:
    root: ./data/storage
    secret: dev-only-hmac-secret
    url_base: http://localhost:8080/files
    public_url: http://localhost:8080/files
```
  </TabItem>
  <TabItem label="s3">
```yaml title="zever.yaml"
storage:
  adapter: s3
  options:
    region: us-east-1
    endpoint: https://s3.us-east-1.amazonaws.com
    access_key_id: AKIAEXAMPLE
    secret_access_key: prod-secret-here
    policy_sync: manual
    sync_fail: warn
    url_base: https://files.example.com
```
  </TabItem>
  <TabItem label="env">
```sh
STORAGE_ADAPTER=s3
STORAGE_REGION=us-east-1
STORAGE_ACCESS_KEY_ID=AKIAEXAMPLE
STORAGE_SECRET_ACCESS_KEY=prod-secret-here
STORAGE_URL_BASE=https://files.example.com
```
  </TabItem>
</Tabs>

`policy_sync` is `manual` or `auto`. `sync_fail` is `warn` or `require`. `endpoint` needs a scheme and host. `r2` needs `account_id`. The `local` adapter defaults `root` to `/tmp/storage`. Without a `secret` it uses an ephemeral key (presigned URLs break on restart), and with `ZEVER_ENV=production` or `prod` it refuses to start. See the [storage options](../../../reference/config/#storage) and [media options](../../../reference/config/#media).

## Mint a presigned URL

Storage addresses objects by `bucket` and `key`. Resolve it with `c.Storage()` (lazy, cached, retried after an error), or open the adapter directly:

```go title="main.go"
package main

import (
	"context"
	"fmt"
	"time"

	storagelocal "github.com/zenta-dev/zever/adapters/storage/local"
	"github.com/zenta-dev/zever/core/storage"
)

func main() {
	ctx := context.Background()
	st, err := storagelocal.New(storage.Options{
		Root:    "./data/storage",
		Secret:  "dev-only-hmac-secret",
		URLBase: "http://localhost:8080/files",
	})
	if err != nil {
		panic(err)
	}
	defer st.Close(ctx)

	up, err := st.PresignUpload(ctx, "receipts", "b_123.pdf", "application/pdf", time.Hour)
	if err != nil {
		panic(err)
	}
	fmt.Println(up.Method) // PUT or POST, per adapter
	down, err := st.PresignDownload(ctx, "receipts", "b_123.pdf", time.Hour)
	if err != nil {
		panic(err)
	}
	fmt.Println(down.Method) // GET
}
```

The `Storage` interface also has `Exists`, `Delete`, `Move` (overwrites the destination; a missing source reports `ErrNotFound`), `Name`, and `Close(ctx)`. Call the interface, not adapter internals, so the policy check always runs.

## Gate access with a policy

`policy` is a flat map. The `default` key covers unlisted buckets, and every other key is a bucket. Each bucket sets rules for `read`, `write`, `update`, and `delete`. A rule has `public`, `allow`, and `deny`, and deny wins. `*` matches any authenticated subject, and `anonymous` matches everyone.

```yaml title="zever.yaml"
storage:
  adapter: local
  options:
    policy:
      default:
        read: { allow: ["*"] }
      receipts:
        read: { allow: ["owner"], deny: ["anonymous"] }
        write: { allow: ["owner"] }
```

## Choose an adapter

| Service | Adapter | Notes |
|---|---|---|
| storage | `local` | Default filesystem store, HMAC presigns via `secret` |
| storage | `s3` | S3-compatible, shared core in `shared/s3opts` |
| storage | `r2` | Cloudflare R2, needs `account_id` |
| media | `local` | Default pipeline root, serves under `base_url` |
| media | `s3` | Shared object hold, needs `bucket` plus credentials |

Storage and media adapters are independent. Keeping them aligned avoids cross-store copies. See the [adapters matrix](../../../reference/adapters-matrix/).

## Production checklist

- Cap everything: media `max_download_bytes` (64 MiB), `max_pixels` (about 50 MP), `max_duration` for video, and `presign_ttl` (1h default, 7-day ceiling). Details live in [Media processing](../media/).
- Never log credentials. `access_key_id` and `secret_access_key` ride file or env, and display goes through `config.RedactedServices`.
- Close order: both are snapshot services that close ahead of leaf `cache` and `queue`, and only resolved services close.
- Skip quietly at the job layer when no source file exists, rather than failing the booking flow.

## Troubleshooting

<details>
<summary>`presign_ttl must be >= 0 and <= 7 days`</summary>

Cause: the window exceeds the 7-day ceiling, often `720h` copied from a sample. Fix: use at most `604800000000000` ns in YAML or `"168h"` in env.
</details>

<details>
<summary>S3 works locally but fails in deploy with endpoint errors</summary>

Cause: `endpoint` lacks a scheme, or `region` is empty on a store that needs it. Fix: set a full URL such as `https://s3.us-east-1.amazonaws.com` and pin `region`.
</details>

<details>
<summary>A second instance returns 404 for a fresh upload</summary>

Cause: `local` with two hosts, each with a private filesystem. Fix: move both to `s3` or `r2` with a shared bucket and re-upload.
</details>
