`storage.Storage` hands out presigned upload/download URLs for opaque objects, gated by one policy. `media` adds the transform pipeline: [Media processing](../media/).

## Quick start

`local` for one instance (under `root`, no infra), `s3`/`r2` to share files.

<Tabs>
  <TabItem label="local">
```sh
STORAGE_ROOT=./data/storage
STORAGE_SECRET=dev-only-hmac-secret
STORAGE_URL_BASE=http://localhost:8080/files
```
  </TabItem>
  <TabItem label="s3">
```sh
STORAGE_REGION=us-east-1
STORAGE_ENDPOINT=https://s3.us-east-1.amazonaws.com
STORAGE_ACCESS_KEY_ID=AKIAEXAMPLE
STORAGE_SECRET_ACCESS_KEY=prod-secret-here
STORAGE_POLICY_SYNC=manual
STORAGE_SYNC_FAIL=warn
STORAGE_URL_BASE=https://files.example.com
```
  </TabItem>
</Tabs>

Backend is wired in code. `policy_sync` is `manual`/`auto`, `sync_fail` `warn`/`require`. `endpoint` needs scheme + host, custom `endpoint` also requires `url_base`. `r2` needs `account_id`. `local` defaults `root` to `/tmp/storage`, without `secret` it uses an ephemeral key (URLs break on restart) and refuses to start under `ZEVER_ENV=production`/`prod`. See [storage options](../../../reference/config/#storage) and [media options](../../../reference/config/#media).

## Mint a presigned URL

Objects use `bucket` + `key`. Use `c.Storage()` (lazy, cached, retried) or open directly:

```go title="main.go" check
package main

import (
	"context"
	"fmt"
	"time"

	storagelocal "github.com/zenta-dev/zever/adapters/storage/local"
	"github.com/zenta-dev/zever/core/storage"
)

func main() {
	ctx := context.Background()
	st, err := storagelocal.New(storage.Options{
		LocalOptions: storage.LocalOptions{
			Root:   "./data/storage",
			Secret: "dev-only-hmac-secret",
		},
		URLBase: "http://localhost:8080/files",
	})
	if err != nil {
		panic(err)
	}
	defer st.Close(ctx)

	up, err := st.PresignUpload(ctx, "receipts", "b_123.pdf", "application/pdf", time.Hour)
	if err != nil {
		panic(err)
	}
	fmt.Println(up.Method) // PUT or POST, per adapter
	down, err := st.PresignDownload(ctx, "receipts", "b_123.pdf", time.Hour)
	if err != nil {
		panic(err)
	}
	fmt.Println(down.Method) // GET
}
```

Also: `Exists`, `Delete`, `Move` (overwrites, missing source → `ErrNotFound`), `Name`, `Close(ctx)`. Call the interface so the policy check runs.

## Gate access with a policy

`policy` is a flat map: `default` covers unlisted buckets, other keys are buckets. Each sets `read`/`write`/`update`/`delete` with `public`/`allow`/`deny` (deny wins). `*` = any authenticated subject, `anonymous` = everyone.

```sh
# STORAGE_POLICY_DEFAULT_READ: no string form in env; set it in Go with container.WithOptions
# STORAGE_POLICY_RECEIPTS_READ: no string form in env; set it in Go with container.WithOptions
# STORAGE_POLICY_RECEIPTS_WRITE: no string form in env; set it in Go with container.WithOptions
```

Storage/media adapters are independent, keep aligned to avoid cross-store copies. See the [adapters matrix](../../../reference/adapters-matrix/).

## Production checklist

- Cap media: `max_download_bytes` (64 MiB), `max_pixels` (~50 MP), `max_duration`, `presign_ttl` (1h, 7-day max). See [Media processing](../media/).
- Never log credentials, display via `config.RedactedServices`.
- Snapshot services: closed ahead of leaf `cache`/`queue`, only resolved services close.
- Skip quietly at the job layer when no source file exists.

## Troubleshooting

<details>
<summary>`presign_ttl must be >= 0 and <= 7 days`</summary>

Over 7-day ceiling (often `720h` from a sample). Use ≤ `604800000000000` ns in YAML or `"168h"` in env.
</details>

<details>
<summary>S3 works locally but fails in deploy with endpoint errors</summary>

`endpoint` lacks scheme or `region` empty. Set full URL (`https://s3.us-east-1.amazonaws.com`), pin `region`.
</details>

<details>
<summary>A second instance returns 404 for a fresh upload</summary>

`local` across two hosts (private filesystems). Move both to `s3`/`r2` with a shared bucket.
</details>
