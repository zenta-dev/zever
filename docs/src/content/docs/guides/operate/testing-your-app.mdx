Zever apps test without Docker, network, or shared state. `config.Default()` picks zero-infra adapters (memory, sqlite, local, log, noop). Every test below runs offline, deterministic. Patterns mirror the runnable samples in `docs/examples/testing_test.go` and `internal/api/api_test.go`.

## Start from zevertest

`github.com/zenta-dev/zever/zevertest` bundles setup into three helpers. `NewTestContainer` registers zero-infrastructure adapters, builds a container from `config.Default()` with per-test sqlite file and storage directory under `t.TempDir()`, silences logging and observability, sets a test JWT secret, and closes it in `t.Cleanup`. `Clock`/`IDs` make time and identifiers deterministic. `Client` drives any `http.Handler` in-process.

```go
import (
    "net/http"
    "testing"

    "github.com/zenta-dev/zever/zevertest"
)

func TestCreateThing(t *testing.T) {
    c := zevertest.NewTestContainer(t)

    r, err := c.Router()
    if err != nil {
        t.Fatalf("Router: %v", err)
    }
    ids := zevertest.NewIDs("thing") // thing-000001, thing-000002, ...
    r.Handle("POST", "/things", func(w http.ResponseWriter, _ *http.Request) {
        w.WriteHeader(http.StatusCreated)
        _, _ = w.Write([]byte(`{"id":"` + ids.Next() + `"}`))
    })

    api := zevertest.NewClient(t, r).WithBearer("token")

    var out struct{ ID string }
    api.Post("/things", map[string]string{"name": "x"}).
        RequireStatus(http.StatusCreated).
        JSON(&out)
    if out.ID != "thing-000001" {
        t.Fatalf("id = %q", out.ID)
    }
}
```

Use `zevertest.NewClock(start)` where code takes a `func() time.Time` (`Clock.Func()`). `Advance` instead of sleeping. `WithConfig(func(*config.Config))` tweaks the config, `WithRegister(func())` registers extra adapters. The rest shows the helpers' internals.

## Open a container per test

Register adapters under test, open a container from `config.Default()`, close it in `t.Cleanup`. Closing shuts down only resolved services, in dependency order.

```go
import (
    "testing"

    cachememory "github.com/zenta-dev/zever/adapters/cache/memory"
    "github.com/zenta-dev/zever/config"
    "github.com/zenta-dev/zever/container"
    "github.com/zenta-dev/zever/core/cache"
)

func TestCacheRoundTrip(t *testing.T) {
    c := container.New(config.Default(), container.Provide(cache.DefaultRef(), cachememory.New))
    t.Cleanup(func() { _ = c.Close(t.Context()) })

    ch, err := c.Cache()
    if err != nil {
        t.Fatalf("Cache: %v", err)
    }
    ctx := t.Context()
    if err := ch.Set(ctx, "k", []byte("v"), 0); err != nil {
        t.Fatalf("Set: %v", err)
    }
    got, err := ch.Get(ctx, "k")
    if err != nil {
        t.Fatalf("Get: %v", err)
    }
    if string(got) != "v" {
        t.Fatalf("Get = %q, want %q", got, "v")
    }
}
```

<Aside type="caution">
`config.Default()` embeds a deterministic dev crypto key. Never ship defaults to production (see [configuration guide](../configuration/)).
</Aside>

## Hit routes with httptest

Build the production router, register routes, serve requests in-process. No port, no network.

```go
import (
    "fmt"
    "io"
    "net/http"
    "net/http/httptest"
    "testing"

    slogadapter "github.com/zenta-dev/zever/adapters/log/slog"
    routerstdhttp "github.com/zenta-dev/zever/adapters/router/stdhttp"
    "github.com/zenta-dev/zever/core/log"
    "github.com/zenta-dev/zever/core/router"
)

func TestGetUser(t *testing.T) {
    logger := slogadapter.NewWithWriter(log.Options{}, io.Discard)
    r, err := routerstdhttp.New(router.Options{AppName: "test", Logger: logger})
    if err != nil {
        t.Fatalf("New: %v", err)
    }

    r.Handle("GET", "/users/{id}", func(w http.ResponseWriter, req *http.Request) {
        fmt.Fprintf(w, "user %s", router.Param(req, "id"))
    })

    rec := httptest.NewRecorder()
    r.ServeHTTP(rec, httptest.NewRequest(http.MethodGet, "/users/42", nil))
    if rec.Body.String() != "user 42" {
        t.Fatalf("body = %q, want %q", rec.Body.String(), "user 42")
    }
}
```

Send authenticated requests with `httptest.NewRequestWithContext(t.Context(), ...)`, setting the `Authorization` header like the todo example's `do` helper.

## Give each test its own sqlite file

`:memory:` sqlite is per-connection unless the DSN shares cache. Point `DB.Options.Path` at a file under `t.TempDir()` for isolated parallel runs, `-shuffle=on`, `-count=N`.

```go
import (
    "path/filepath"
    "testing"

    dbsqlite "github.com/zenta-dev/zever/adapters/db/sqlite"
    "github.com/zenta-dev/zever/core/db"
)

func TestDBRoundTrip(t *testing.T) {
    conn, err := dbsqlite.New(db.Options{Path: filepath.Join(t.TempDir(), "test.db")})
    if err != nil {
        t.Fatalf("New: %v", err)
    }
    t.Cleanup(func() { _ = conn.Close(t.Context()) })

    ctx := t.Context()
    if _, err := conn.Exec(ctx, "CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT)"); err != nil {
        t.Fatalf("create: %v", err)
    }
    if _, err := conn.Exec(ctx, "INSERT INTO users (name) VALUES (?)", "ada"); err != nil {
        t.Fatalf("insert: %v", err)
    }
    rows, err := conn.Query(ctx, "SELECT name FROM users")
    if err != nil {
        t.Fatalf("query: %v", err)
    }
    defer func() { _ = rows.Close() }()
    for rows.Next() {
        var name string
        if err := rows.Scan(&name); err != nil {
            t.Fatalf("scan: %v", err)
        }
        if name != "ada" {
            t.Fatalf("name = %q, want %q", name, "ada")
        }
    }
}
```

The sqlite adapter rewrites `?` placeholders per dialect. The same body runs against postgres in cover tests.

## Conformance kits for custom adapters

Each battery ships a conformance kit (`dbtest`, `outboxtest`, `cachetest`, `authtest`, ...) proving backend parity: round-trips, error wrapping, transactions, retry, DLQ, dedupe.

```go
import (
    "context"
    "testing"

    "github.com/zenta-dev/zever/adapters/outbox/memory"
    coredb "github.com/zenta-dev/zever/core/db"
    "github.com/zenta-dev/zever/core/outbox/outboxtest"
)

func TestConformance(t *testing.T) {
    t.Parallel()

    outboxtest.Conformance(t, func(_ *testing.T, pub *outboxtest.Recorder) outboxtest.Harness {
        s, err := memory.New(memory.Options{Publisher: pub})
        if err != nil {
            t.Fatalf("New() error = %v", err)
        }
        return outboxtest.Harness{
            Store: s,
            InTx: func(ctx context.Context, fn func(context.Context, coredb.Tx) error) error {
                return fn(ctx, nil)
            },
        }
    })
}
```

The database kit:

```go
import (
    "path/filepath"
    "testing"

    dbsqlite "github.com/zenta-dev/zever/adapters/db/sqlite"
    "github.com/zenta-dev/zever/core/db"
    "github.com/zenta-dev/zever/core/db/dbtest"
)

func TestDBConformance(t *testing.T) {
    t.Parallel()

    dbtest.Conformance(t, func(t *testing.T) db.DB {
        conn, err := dbsqlite.New(db.Options{Path: filepath.Join(t.TempDir(), "kit.db")})
        if err != nil {
            t.Fatalf("New: %v", err)
        }
        t.Cleanup(func() { _ = conn.Close(t.Context()) })
        return conn
    })
}
```

<Aside type="tip">
Never register a fixed adapter name in tests: registries are process-global with no unregister, so a second `-count=N` iteration collides. Open via the constructor directly, or mint a unique name per invocation.
</Aside>

## Keep time deterministic

No `time.Sleep` for synchronization, no timing assertions, no unseeded randomness, no network. Instead:

- Wait on channels, `sync` primitives, or a polling `waitFor` helper with a deadline.
- Prefer `testing/synctest` bubbles for timeout and deadline assertions: the fake clock makes "wait, then assert" instant.
- Inject clocks into code under test (`Now func() time.Time` field or small clock interface) so expiry and retry tests set time.

## Catch goroutine leaks

Services spawning background work (queue promoter, scheduler cron) drain on `Close`. `goleak.VerifyTestMain` in a `TestMain` fails the package on a leaked goroutine:

```go
import (
    "testing"

    "go.uber.org/goleak"
)

func TestMain(m *testing.M) {
    goleak.VerifyTestMain(m)
}
```

The container's leak tests live behind the `leak` tag (`go test -tags=leak ./container/`) so the default suite stays fast. Filter only process-lifetime third-party workers. Keep timeout tests short (roughly 100ms parent, 500ms block), asserting observable behavior, never elapsed wall-clock time.
