`webhook` sends signed outbound events via `Register`/`Unregister`/`Deliver` fan-out. Signatures are `t=<timestamp>,v1=<hex-hmac>` over `<timestamp>.<payload>`, verified with `hmac.Equal` inside a timestamp window. No top-level API key in `Options`: each target gets its own secret at `Register`, so one leak never exposes every integration.

## Quick start

```sh
WEBHOOK_TIMEOUT=10s
WEBHOOK_MAX_RETRIES=3
WEBHOOK_QUEUE_ADAPTER=memory
WEBHOOK_DEAD_LETTER_TOPIC=webhook.dead
WEBHOOK_REPLAY_TOLERANCE=5m
```

```sh
WEBHOOK_MAX_RETRIES=3
WEBHOOK_REPLAY_TOLERANCE=5m
BOOKINGS_WEBHOOK_CREATED_TARGET=https://partner.example.com/hooks
BOOKINGS_WEBHOOK_CREATED_SECRET=per-target-secret
```

`queue_opts` (`visibility_timeout`, `poll_timeout`, `buffer`) has no string form, wire it in Go via `container.WithOptions`. Never commit per-target secrets. `Validate` rejects negative `timeout`/`max_retries`/`replay_tolerance`. The queue adapter (not core) enforces queue rules (adapter required, visibility exceeding timeout). All keys: [webhook config reference](../../../reference/config/#webhook).

## Register a target and deliver

```go title="main.go" check
package main

import (
	"context"
	"fmt"

	webhookhttp "github.com/zenta-dev/zever/adapters/webhook/http"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/webhook"
)

func main() {
	c := container.New(config.Default(), container.Provide(webhook.DefaultRef(), webhookhttp.New))
	wh, _ := c.Webhook()
	defer wh.Close()

	target := "" // empty means skip, like RegisterDemoTargets
	if target == "" {
		fmt.Println("delivery skipped: no target configured")
		return
	}
	_ = wh.Register(context.Background(), "booking.created", target, "secret")
}
```

```text
delivery skipped: no target configured
```

With a target and the `http` adapter, `Deliver` POSTs the signed payload to every subscriber, signature in `X-Hub-Signature-256` (`queue` uses `X-Webhook-Signature`, verified before delivery). `Webhook()` resolves lazily, caches, retries after errors, `Close() error` takes no context. See [the container](../../../concepts/container/).

Bookings wires the `queue` backend in code. Demo targets come from env only (`BOOKINGS_WEBHOOK_CREATED_TARGET`/`_SECRET`, plus the `CANCELLED` pair). `RegisterDemoTargets` skips empty targets, so unconfigured delivery is quietly skipped.

## Choose an adapter

| Adapter | Package | Use when |
|---|---|---|
| `http` | `adapters/webhook/http` | Default. Direct POST with no durability. A crash mid-delivery loses the event. |
| `queue` | `adapters/webhook/queue` | Delivery rides the [queue](../queue/): at-least-once, exponential redelivery backoff (500ms base, 72h cap, up to `max_retries`), then the dead-letter topic. |

With `http`, N replicas mean N independent retry loops. Prefer `queue`: retries funnel through shared infrastructure with a dead-letter topic (`webhook.dead` in the demo). The bookings README notes the queue variant needs its queue reference wired before doctor goes green.

## Production checklist

- Never log per-target secrets or raw option maps (`config.RedactedServices`).
- Verifiers check HMAC (constant-time) plus timestamp inside `replay_tolerance` (default 5m).
- Keep `allow_private_targets` false in production (no SSRF). Container closes only resolved services, joining errors via `errors.Join`.  

## Troubleshooting

| Symptom | Fix |
|---|---|
| Webhook silently does nothing | Target env empty, registration skipped by design and not an error path, set `BOOKINGS_WEBHOOK_CREATED_TARGET` + secret, restart worker |
| Signatures verify but replays succeed | Timestamp window unchecked, enforce `replay_tolerance` on embedded `t=` so hour-old payloads are rejected |
| Queue adapter open fails | `queue_adapter` unset or `visibility_timeout` must exceed `timeout`, mirror bookings (memory, 30s visibility over 10s timeout) |
