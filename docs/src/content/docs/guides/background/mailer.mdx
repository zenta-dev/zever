`mailer.Mailer` sends transactional mail: receipts, cancellations, password resets. Defaults to `log` (validated messages go to the log, not the wire), real delivery is an explicit adapter change. Validated delivery only (no templates, no lists): build the finished `Mail` with `NewMail`, or a `Sender` binding the default `From`. Stay on `log` for dev/CI, `smtp` for production, there is no in-between adapter. Enqueue sends as jobs so SMTP blips retry at the job layer.

## Quick start

```sh
MAILER_HOST=localhost
MAILER_PORT=25
```

`host`/`port` are required by `Validate` even for `log` (never dials), bookings uses the dummy localhost pair for that reason.

```go title="main.go" check
package main

import (
	"context"
	"fmt"

	maillog "github.com/zenta-dev/zever/adapters/mailer/log"
	"github.com/zenta-dev/zever/core/mailer"
)

func main() {
	m, _ := maillog.New(mailer.Options{Host: "localhost", Port: 25})
	defer m.Close()

	msg := mailer.NewMail(
		mailer.Address{Address: "bookings@example.com"},
		[]mailer.Address{{Address: "guest@example.com"}},
		"Booking confirmed",
		"Space Loft, Fri to Sun. Receipt inside.",
	)
	_ = m.Send(context.Background(), &msg)
	fmt.Println("logged, not delivered")
}
```

```text
{"from":{"address":"bookings@example.com"},"to":[{"address":"guest@example.com"}],"cc":[],"bcc":[],"subject":"Booking confirmed","body":"Space Loft, Fri to Sun. Receipt inside.","html":"","attachments":[]}
logged, not delivered
```

`Send` validates, writes one JSON line to stdout (attachments log name/size only), returns nil without a socket. Tests use `maillog.NewWithWriter(opts, w)`.

## Send through SMTP

<Tabs>
  <TabItem label="YAML">

```sh
MAILER_HOST=mail.example.com
MAILER_PORT=587
MAILER_USERNAME=bookings
MAILER_PASSWORD=prod-secret-here
MAILER_ENCRYPTION=starttls
MAILER_TIMEOUT=30s
MAILER_MAX_MESSAGE_SIZE=10485760
```
  </TabItem>
  <TabItem label="Env">
```sh
MAILER_HOST=mail.example.com
MAILER_PORT=587
MAILER_USERNAME=bookings
MAILER_PASSWORD=prod-secret-here
MAILER_ENCRYPTION=starttls
MAILER_TIMEOUT=30s
```
  </TabItem>
</Tabs>

- `encryption`: `starttls` (default when empty), `implicit`, or `none`.
- `timeout`: zero means the 30s default. Durations take Go strings such as `"30s"`.
- `max_message_size`: zero means 10 MiB default, larger fails with `ErrMessageTooLarge`.

Env keys are strict snake_case (`MAILER_HOST`, `MAILER_PORT`, `MAILER_TIMEOUT`). All keys: [mailer config reference](../../../reference/config/#mailer).

| Adapter | Package | Notes |
|---|---|---|
| `log` | `adapters/mailer/log` | Default, safe sink, writes each message as a JSON line |
| `smtp` | `adapters/mailer/smtp` | Production delivery, honors encryption and timeout |

Both serve `mailer.Mailer` (`Send` + `Close`), delivery errors stay `errors.Is`-compatible for job-layer retry branching.

## Resolve the mailer from the container

```go title="main.go"
m, err := c.Mailer()
```

`Mailer()` resolves lazily and caches, on error the cache clears. Address helpers live in `core/mailer/address.go`, attachments in `core/mailer/mail.go`. `Close() error` is instant, the container probes it as a snapshot service. See [the container](../../../concepts/container/).

## Production checklist

- `EncryptionNone` + `username`/`password` fails validation (no plaintext credentials). `implicit` only when the provider documents it.
- `username`/`password` together or neither, a lone value fails instead of half-authenticating.
- `host` without scheme (`mail.example.com`, not `smtp://...`), port 1-65535.
- Parse user input via `core/mailer/address.go` (rejects header injection/controls) before `From`.
- Small attachments, or link `storage` presigned URLs. Passwords by file/env only, config via `config.RedactedServices`, keep error text to names and reasons.
- Retry transient failures at the job layer (bookings `SendConfirmation`: `max_attempts(3)`, 30s exponential base).

## Troubleshooting

| Symptom | Fix |
|---|---|
| `host must be non-empty` on boot (`log`) | `host`/`port` zero, set `MAILER_HOST=localhost`, `MAILER_PORT=25` |
| `username and password must be set together` | Only one supplied, set both from one secret source or clear both |
| `encryption none must not carry credentials` | `none` + auth values, switch to `starttls`/`implicit` or drop credentials |
| Local sends pass, production times out | Wrong port/encryption or blocked egress, confirm tuple (587/`starttls`, 465/`implicit`), raise `timeout`, send behind `job.Dispatcher` |
