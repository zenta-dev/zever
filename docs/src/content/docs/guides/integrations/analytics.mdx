`analytics.Analytics` offers `Track`, `Identify`, `Group` across `log` (default) and `posthog`.

## Quick start

```sh
ANALYTICS_ANONYMOUS_ID=anonymous
ANALYTICS_GROUP_TYPE=organization
ANALYTICS_MAX_PROPERTIES_BYTES=65536
ANALYTICS_MAX_PROPERTIES=100
```

Defaults: `anonymous_id` `anonymous`, `group_type` `organization`, `max_properties_bytes` 64KiB. `endpoint` must use https or localhost http, `max_properties` bounds count, negatives rejected. See [analytics config reference](../../../reference/config/#analytics).

```go title="main.go" check
package main

import (
	"context"
	"fmt"

	analyticslog "github.com/zenta-dev/zever/adapters/analytics/log"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/analytics"
)

func main() {
	c := container.New(config.Default(), container.Provide(analytics.DefaultRef(), analyticslog.New))
	defer c.Close(context.Background())

	an, err := c.Analytics()
	if err != nil {
		panic(err)
	}
	_ = an.Track(context.Background(), "signup", map[string]any{"plan": "pro"})
	_ = an.Identify(context.Background(), "user-1", map[string]any{"email": "you@example.com"})
	_ = an.Group(context.Background(), "user-1", "acme", nil)
	_ = an.Close()
	fmt.Println("tracked 1 event for user-1")
}
```

Expected output (`Track` falls back to `anonymous_id` when the context has no user):

```text
{"level":"INFO","msg":"track","user_id":"anonymous","event":"signup","properties":"{\"plan\":\"pro\"}"}
{"level":"INFO","msg":"identify","user_id":"user-1","traits":"{\"email\":\"you@example.com\"}"}
{"level":"INFO","msg":"group","user_id":"user-1","group_id":"acme","traits":"null"}
tracked 1 event for user-1
```

## Choose an adapter

| Adapter | Package | Notes |
|---|---|---|
| `log` | `analytics/log` | Default, no PII redaction, never a production fallback. |
| `posthog` | `analytics/posthog` | Needs `api_key`. Keeps upstream field spelling (`DistinctId`). |

## Production checklist

- `posthog` buffers, `Close()` before exit or lose the last batch.
- Oversize properties fail fast with `ErrPropertiesTooLarge`, nothing is truncated.
- Never log raw options, use `cfg.RedactedServices()`, keep the key in [Secrets](../../security/secrets/).

## Troubleshooting

<details>
<summary>Events vanish on shutdown</summary>

Missing `Close()`, flush handle and container before exit.
</details>

<details>
<summary>Payload too large</summary>

Over `max_properties_bytes` or `max_properties`, trim the map or raise the bound.
</details>
