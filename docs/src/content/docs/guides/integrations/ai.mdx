`ai.AI` exposes `Generate`, `Stream`, `Embed` with typed messages, tools, usage, provider set in config (`anthropic`, `openai`, `gemini`, `ollama`). `config.Default()` uses `anthropic`, `Validate` needs an API key, or `base_url` plus key.

## Quick start

```sh
AI_API_KEY=sk-...
AI_MODEL=claude-opus-4
AI_TIMEOUT=30s
```

```sh
AI_API_KEY=sk-...
AI_MODEL=gpt-5
AI_TIMEOUT=30s
AI_BASE_URL=https://proxy.internal/v1
```

`base_url` suits proxies or self-hosted gateways, it must be `https` with scheme and host. `timeout` bounds each request, negatives rejected. See [AI config](../../../reference/config/#ai).

```go title="main.go" check
package main

import (
	"context"
	"fmt"

	aianthropic "github.com/zenta-dev/zever/adapters/ai/anthropic"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/ai"
)

func main() {
	c := container.New(config.Default(), container.Provide(ai.DefaultRef(), aianthropic.New))
	defer c.Close(context.Background())

	backend, err := c.AI()
	if err != nil {
		fmt.Println("resolve error:", err)
		return
	}
	out, err := backend.Generate(context.Background(), "", []ai.Message{
		{Role: ai.RoleUser, Content: "Say hi in five words."},
	}, ai.GenerateOptions{})
	if err != nil {
		fmt.Println("generate error:", err)
		return
	}
	fmt.Println("text:", out.Content)
	fmt.Println("tokens:", out.Usage.PromptTokens+out.Usage.CompletionTokens)
}
```

Expected output:

```text
text: Hello, glad you are here.
tokens: 24
```

Range `Stream` until close, the bounded channel prevents goroutine leaks.

## Adapters

| Adapter | Package | Notes |
| --- | --- | --- |
| `anthropic` | `adapters/ai/anthropic` | Default, needs `api_key`. |
| `openai` | `adapters/ai/openai` | Needs `api_key`. |
| `gemini` | `adapters/ai/gemini` | Needs `api_key`. |
| `ollama` | `adapters/ai/ollama` | Self-hosted, `base_url` maps to `Addr`. |

`ollama.New` takes `ollama.Options{Addr}`, wire with `container.Provide(AI, aiollama.New)`. The container maps `AI_BASE_URL` to `Addr` plus `AI_MODEL`, `AI_TIMEOUT`, `AI_ALLOW_INSECURE`, `AI_ALLOW_PRIVATE`, `AI_INSECURE_SKIP_VERIFY`. Non-loopback endpoints need `https`, outbound dials allow only globally routable addresses, no redirects. Loopback sidecars need `allow_private: true` (logged). TLS stays verified unless `insecure_skip_verify: true` (warns), `allow_insecure` permits only `http`, never skips verification.

## Agents and RAG

`agent`/`rag` build on `ai` with no config entry, resolve cached `c.Agent()`/`c.RAG()`, or `New` with `AI()` and `VectorStore()`.

`core/agent` loops generate, dispatch, append until answer or step bound, unknown tools fail closed and handler errors return to the model.

```go title="agent.go"
loop, err := agent.New(backend, agent.Options{
	Model: "gpt-5",
	Tools: []agent.Tool{{
		Name:        "lookup_order",
		Description: "Look up an order by ID.",
		Parameters:  map[string]any{"type": "object"},
		Handler: func(ctx context.Context, args map[string]any) (string, error) {
			return "order 42", nil
		},
	}},
})
```

`core/rag` embeds chunks into a `vectorstore`, retrieves context, and generates a grounded answer.

```go title="rag.go"
engine, err := rag.New(backend, store, rag.Options{Model: "gpt-5"})
```

## Give coding agents the compiler over MCP

`tools/zever-mcp` is a stdio [MCP](https://modelcontextprotocol.io) server for the `.zen` compiler: seven tools over newline-delimited JSON-RPC 2.0 (`initialize`, `tools/list`, `tools/call`). Six are read-only, `zever_generate` writes only after dry-run preview plus human approval.

| Tool | Purpose |
| --- | --- |
| `zever_compile` | Compile `.zen` sources. Return merged OpenAPI. |
| `zever_schema` | JSON overview of modules, entities, services, messages, enums. |
| `zever_explain` | Describe a module, entity, message, service, or operation by dotted path. |
| `zever_check` | Validate `.zen` (parse and resolve). Returns `ok` or `file:line:col`. |
| `zever_routes` | List declared HTTP routes as JSON (`method`, `path`, target). |
| `zever_doctor` | Resolve batteries. Report OK/FAIL. |
| `zever_generate` | Dry-run plan, then apply on approval. |

Plus static reference resources and prompt templates.

```sh
go build -o zever-mcp ./tools/zever-mcp
```

```json
{ "mcpServers": { "zever": { "command": "/path/to/zever-mcp" } } }
```

## Production checklist

- Keep keys in env (`AI_API_KEY`), never in code, inspect via `config.RedactedServices()`. `APIKey` never appears in logs or errors.
- Set `timeout` per deploy, zero uses the adapter default, which may exceed handler deadlines.
- Pin `model`, provider defaults can change pricing.
- Unsupported features fail closed with `ErrNotSupported`.

## Troubleshooting

<details>
<summary>`AI()` fails with an invalid-options error at startup</summary>

Missing key or bad `base_url`, check `AI_API_KEY` and that `AI_BASE_URL` has `https` scheme and host.
</details>

<details>
<summary>`Generate` returns `ErrNotSupported`</summary>

The provider lacks that feature shape. Gate per adapter or switch, the facade never downgrades silently.
</details>

<details>
<summary>Token usage looks wrong after switching providers</summary>

Usage follows each provider's shape, compare `Usage` before billing on totals.
</details>
