`billing.Billing` facades provider APIs (customers, subscriptions, invoices, minor units). Charges: [Payments](../payment/).

## Quick start

`stub` is default: zero-infra, in-memory, test-safe.

```sh
BILLING_SANDBOX=true
```

Provider keys from `shared/providersopt`: `secret_key` (Stripe), `api_key` (Paddle), `endpoint` (absolute URL), `sandbox`. See [billing config reference](../../../reference/config/#billing).

```go title="main.go" check
package main

import (
	"context"
	"fmt"

	billingstub "github.com/zenta-dev/zever/adapters/billing/stub"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/billing"
)

func main() {
	c := container.New(config.Default(), container.Provide(billing.DefaultRef(), func(_ billing.Options) (billing.Billing, error) {
		return billingstub.New(), nil
	}))
	ctx := context.Background()
	defer c.Close(ctx)

	b, err := c.Billing()
	if err != nil {
		panic(err)
	}
	cust, _ := b.CreateCustomer(ctx, "Ada", "ada@example.com", "key-1")
	sub, _ := b.CreateSubscription(ctx, cust.ID, "plan-pro", "key-2")
	inv, _ := b.GetInvoice(ctx, cust.ID)
	fmt.Println("customer:", cust.ID)
	fmt.Println("subscription:", sub.ID, string(sub.Status))
	fmt.Println("invoice due:", inv.AmountDue)
	_ = b.Close()
}
```

Expected output (IDs are `cus_`/`sub_` plus a random ULID, so they vary):

```text
customer: cus_01J0000000000000000000000
subscription: sub_01J0000000000000000000001 active
invoice due: 0
```

## Minor units and idempotency keys

Amounts are `int64` minor units, use currency exponent helpers and one stable idempotency key per create.

## Choose an adapter

| Adapter | Package | Notes |
|---|---|---|
| `stub` | `adapters/billing/stub` | Default, in-memory ULID records. |
| `stripe` | `adapters/billing/stripe` | Needs `secret_key`. |
| `paddle` | `adapters/billing/paddle` | Needs `api_key`. |

## Production checklist

- The provider is the system of record, `billing` gives typed create/query, no per-provider HTTP.
- Never log `SecretKey`/`APIKey`, hold them in [Secrets](../../security/secrets/).

## Troubleshooting

<details>
<summary>Tests hit the real provider</summary>

Wrong backend, check `container.Provide` (tests default to `stub`).
</details>

<details>
<summary>Amounts are off by a factor of 100</summary>

Major units passed, multiply by currency exponent (`ParseMinorUnits`) before create.
</details>
