`Geo` covers `Geocode`, `ReverseGeocode`, `Distance` (meters) with fixed callers.

## Quick start

`static` (default): file-backed in-memory list, `path` points at a JSON fixture.

```sh
GEO_PATH=data/cities.json
```

```go title="main.go" check
package main

import (
    "context"
    "fmt"

    geostatic "github.com/zenta-dev/zever/adapters/geo/static"
    "github.com/zenta-dev/zever/config"
    "github.com/zenta-dev/zever/container"
    "github.com/zenta-dev/zever/core/geo"
)

func main() {
    c := container.New(config.Default(), container.Provide(geo.DefaultRef(), geostatic.New))
    g, _ := c.Geo()
    defer g.Close()

    ctx := context.Background()
    locs, _ := g.Geocode(ctx, "Berlin")
    fmt.Println(len(locs))
    d, _ := g.Distance(ctx, geo.Point{Lat: 52.52, Lng: 13.40}, geo.Point{Lat: 48.85, Lng: 2.35})
    fmt.Println(d)
}
```

```text
1
877676.52...
```

`1` assumes Berlin, `Distance` is haversine (6371 km sphere, meters) and `ValidCoord` checks WGS84 range and finiteness. Bookings wires `static` at `testdata/cities.json`.

## OSM and Google

`osm` is free (OpenStreetMap), `google` is paid accuracy.

```sh
GEO_ENDPOINT=https://nominatim.openstreetmap.org
GEO_USER_AGENT=bookings-demo/1.0
```

```sh
GEO_API_KEY=your-key
GEO_BASE_URL=https://maps.googleapis.com
```

`Validate` rejects negative `timeout`/`max_response_body` and non-`https` `base_url`/`endpoint` unless `allow_insecure`. Outbound dials: only globally routable addresses, no redirects. Local endpoints need `allow_private: true` (logged). See [geo config reference](../../../reference/config/#geo).

| Adapter | Package | Notes |
|---|---|---|
| `static` | `adapters/geo/static` | Default. File-backed, offline, deterministic. |
| `osm` | `adapters/geo/osm` | Requires `user_agent`. |
| `google` | `adapters/geo/google` | Needs `api_key`. |

## Production checklist

- `Close() error` takes no context, container closes in dependency order, joining errors.
- `static` is per-process, cache/job remote `osm`/`google`.
- `api_key` is secret, never log raw options, use `cfg.RedactedServices()`.

## Troubleshooting

<details>
<summary>`zever doctor` reports FAIL on geo</summary>

Zero-infra defaults read `cities.json` from the working dir, seed the fixture or point `path` at committed test data.
</details>

<details>
<summary>`base_url must use https`</summary>

External adapters require a valid `https` URL (`allow_insecure` is test-only).
</details>

<details>
<summary>OSM rejects requests</summary>

`user_agent` missing or generic, set an app-identifying `User-Agent` per Nominatim policy and cache results.
</details>
