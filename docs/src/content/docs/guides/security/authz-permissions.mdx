title: Authorization
description: Guard routes and RPCs with allow or deny checks using noop, RBAC, or Casbin.
---

`permission` answers what a caller may do via `Can(subject, action, resource)`: `allow`, `implicit_deny`, `explicit_deny`, with `noop` (`permission/noop`, default, denies all), `rbac` (`permission/rbac`), `casbin` (`permission/casbin`). Identity comes from [Authentication](../auth/).

## Quick start

Default `noop` denies every check (`implicit_deny`), placeholder only.

```go title="main.go"
p, err := c.Permission()
if err != nil {
    return err // config invalid or policy files unreadable
}
```

`rbac` checks in-memory `rules` (`role`, `action`, `effect`, `owned_only`) and `roles`. `casbin` reads `model_path` plus `policy_path` together, `rules` must then be empty. See [reference](../../../reference/config/#permission).

## Guard HTTP and gRPC

`authz` has no container accessor, it composes `Auth()` and `Permission()`: HTTP takes a `Policy` plus resource-ID extractor, gRPC a method-policy map.

```go title="guard.go"
authn, err := c.Auth()
if err != nil {
    return err
}
checker, err := c.Permission()
if err != nil {
    return err
}

pol := authz.Policy{AuthRequired: true, PermissionCheck: "spaces.read", ResourceType: "space"}
guarded := authz.Middleware(authn, checker, pol, func(r *http.Request) string {
    return r.PathValue("id")
})(handler)

policies := map[string]authz.Policy{
    "/booking.BookingService/Book": {AuthRequired: true, PermissionCheck: "bookings.write", ResourceType: "booking"},
}
guardedUnary := authz.UnaryServerInterceptor(authn, checker, policies)
```

Matching grants reach the handler, others denied. Treat a `Can` error as denial. gRPC reads resource id from `ResourceIDer`, `GetId` (not `GetID`) matches the `protoc-gen-go` getter:

```go
type ResourceIDer interface {
    GetId() string
}
```

Decisions: `allow`, `implicit_deny` (no rule matched), `explicit_deny` (rule refused). Denials, unknown roles, and missing policies fail closed. `model_path` and `policy_path` reject `..` and must exist at `Open`.

## Production checklist

- Replace `noop` before any protected deployment, audit the value.
- Deny unknown answers and checker errors.
- Never add a method to public `Checker`, add a smaller interface.
- Version policy files and sync across instances.

## Troubleshooting

<details>
<summary>Every request is denied</summary>

Default backend is `noop`. Wire `rbac`/`casbin` in `internal/app/wiring.go` and rebuild.
</details>

<details>
<summary>`Open` fails on policy paths</summary>

Path uses `..` or is missing. Use a repo-relative path.
</details>

<details>
<summary>Denials for valid roles</summary>

Role or resource differs from policy (case, prefix, plural). Compare exact `Can` arguments.
</details>

<details>
<summary>`Can` errors under load</summary>

Store unreachable. Treat as denial, check connectivity.
</details>
