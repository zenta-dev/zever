---
title: Rate limiting
description: Bound request rates per key with token buckets in memory or shared over Redis.
---

`ratelimit` bounds one key's (user, IP, token) endpoint rate, `Limiter.Allow` returns a `Decision` with `Allowed`, `RetryAfter`, `Remaining`. Map denials to `429`, fail mode is your call.

## Quick start

Default: `memory`, `rate: 10`, `burst: 20`. `rate` (refill/sec), `burst` (bucket size): both required, positive, finite.

```sh
RATELIMIT_RATE=10
RATELIMIT_BURST=20
```

```go title="main.go"
rl, err := c.RateLimit() // c.Ratelimit() is an alias
if err != nil {
    return err
}
defer rl.Close()
for i := 0; i < 3; i++ {
    dec, err := rl.Allow(ctx, "book:guest-1", 1)
    fmt.Println(dec.Allowed, dec.Remaining, err)
}
```

```text
true 19 <nil>
true 18 <nil>
true 17 <nil>
```

## Limit requests

Bookings handler: `Allow(ctx, "book:"+guest, 1)` → `429` when `!dec.Allowed`, `500` on error, charges cap at burst. Generated servers wire `middleware.RateLimit` (HTTP `429` + `Retry-After`) and a gRPC `ResourceExhausted` interceptor when the battery has a provider, both fail open, `WithFailMode(FailClosed)` opts in.

## Share across replicas

Per-instance buckets multiply effective limits (`limit x replicas`), switch to `redis` with multiple replicas.

```sh
RATELIMIT_RATE=100
RATELIMIT_BURST=200
RATELIMIT_REDIS_ADDR=127.0.0.1:6379
RATELIMIT_REDIS_PREFIX=rl
```

Distinct `redis.prefix` per environment. Durations are Go strings (`idle_ttl` 10m, `sweep_interval` 1m, e.g. `"5s"`). `Validate` rejects non-positive `rate`/`burst`, negative `idle_ttl`/`sweep_interval`, bad Redis `addr`/`prefix`. `ratelimit/memory` (default), `ratelimit/redis`. Keys: [reference](../../../reference/config/#ratelimit).

## Production checklist

- `Limiter.Close() error` takes no context, errors join via `errors.Join`, panics become `*ClosePanicError`.
- PII keys (IP, user ID), `InvalidKeyError` reports only length.
- Never log raw options, use `cfg.RedactedServices()`.

## Troubleshooting

<details>
<summary>Limit looks multiplied</summary>

Replicas on `memory`, move to `redis` or divide per-instance rate by count.
</details>

<details>
<summary>`rate must be > 0 and finite`</summary>

`rate`/`burst` required. Empty options fail `Validate` (bookings example: `RATELIMIT_RATE=10`, `RATELIMIT_BURST=20` in `.env`).
</details>

<details>
<summary>`InvalidKeyError` on `Allow`</summary>

256-byte key cap (`MaxKeyLen`), no control bytes, hash or truncate long composite keys.
</details>
