title: Password hashing
description: Hash and verify passwords with Argon2id and rehash when parameters change.
---

`password` Argon2id hashing, verification, rehash flagging, stores and issues nothing.

## Quick start

```sh
PASSWORD_TIME=3
PASSWORD_MEMORY=65536
PASSWORD_THREADS=4
```

Defaults: `time` 3 (1 to 10), `memory` 65536 KiB (64 MiB, 8 MiB to 1 GiB), `threads` 4 (1 to 16), `salt_length` 16 (8 to 64), `key_length` 32 (16 to 128). Out-of-range fails `Open`. Over-1024-byte plaintext returns `ErrPasswordTooLong`. See [password reference](../../../reference/config/#password).

## Hash and verify

```go title="login.go"
pw, err := c.Password()
if err != nil {
    return err
}
hash, err := pw.Hash(ctx, "correct horse battery staple")
if err != nil {
    return err
}
ok, err := pw.Verify(ctx, hash, "correct horse battery staple")
if err != nil {
    return err
}
rehash, err := pw.NeedsRehash(ctx, hash)
```

```text
hash:   $argon2id$v=19$m=65536,t=3,p=4$<salt>$<key>
ok:     true
rehash: false (true after a cost-parameter bump)
```

PHC form, `crypto/rand` salts, constant-time comparison. `Verify` returns `true, nil` (match), `false, nil` (mismatch, reject generically), `_, ErrInvalidHash` (corrupt, force reset), check the sentinel with `errors.Is`.

## Retune costs

1. Benchmark on production-class hardware, not a laptop.
2. Deploy, old hashes keep verifying.
3. On login, `NeedsRehash` flags stale hashes, rehash and persist.
4. Track stale count to zero.

## Production checklist

- Rate-limit login, hashing cost is not an attempt limit ([Rate limiting](../ratelimit/)).
- Never log passwords or hashes, errors name the failure, not the value.

## Troubleshooting

<details>
<summary>`ErrInvalidHash`</summary>

Truncated or corrupted value. Confirm with `errors.Is`, force reset.
</details>

<details>
<summary>Slow logins</summary>

Costs exceed capacity. Benchmark, lower toward defaults, scale out.
</details>

<details>
<summary>`NeedsRehash` always true</summary>

Parameters changed since minting, rehash on next login.
</details>

<details>
<summary>Length rejection</summary>

Plaintext exceeds 1024 bytes, reject at the boundary.
</details>
