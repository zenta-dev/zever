---
title: Secrets
description: Read named credentials from the environment or Vault, separate from layered config.
---

`secrets` returns one named credential on demand, never a YAML file or log line, for API keys, webhook signing secrets, and provider tokens, separate from layered `config`.

## Quick start

```sh
SECRETS_PREFIX=ZEVER
```

```sh
SECRETS_PREFIX=ZEVER
ZEVER_STRIPE_KEY=sk_live_...
ZEVER_WEBHOOK_SECRET=whsec_...
```

`prefix` is required (default `ZEVER`), no `/`, `..`, spaces. `DEMO_KEY` reads `ZEVER_DEMO_KEY` exactly. See [reference](../../../reference/config/#secrets).

## Read a secret

```go title="main.go" check
package main

import (
	"context"
	"fmt"
	"os"

	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
)

func main() {
	os.Setenv("ZEVER_DEMO_KEY", "s3cr3t")
	c := container.New(config.Default())
	ctx := context.Background()
	defer c.Close(ctx)

	s, err := c.Secrets()
	if err != nil {
		fmt.Println("resolve error:", err)
		return
	}
	val, _ := s.Get(ctx, "DEMO_KEY")
	fmt.Println("bytes:", len(val))
	names, _ := s.List(ctx)
	fmt.Println("count:", len(names))
}
```

```text
bytes: 6
count: 1
```

Assert lengths, never values. `Secrets()` resolves lazily, `Close(ctx)` takes a context, unlike most services.

## Vault for rotation

`env` is read-only: `Set`/`Delete` return `secrets.ErrNotSupported`, rotation means restarting with new env values. For payments: `vault` (KV v2) `Get`/`Set`/`Delete`/`List` over HTTP, 5s timeout, values never in errors.

```sh
SECRETS_ADDR=https://vault.internal:8200
SECRETS_MOUNT=secret
SECRETS_TOKEN_FILE=/run/secrets/vault-token
```

`addr` (scheme + host, `https` only unless `allow_insecure: true` for tests), `mount` (no spaces, `..`, empty/dot segments, `/`-segments URL-escaped, so `team/secret` works), one of `token`/`token_file` required. `namespace` optional. `token_file` must be owner-readable (`0600` or stricter) unless `allow_insecure_token_file_perms: true`. Wire `container.Provide` (`adapters/secrets/vault`). `secrets/env` (default, read-only), `secrets/vault`. Names must match `[A-Za-z0-9._-]+` (`ValidateName`).

## Production checklist

- Prefer `secrets` over config env for money/auth signing: `payment` `webhook_secret`, `auth` JWT secret, provider keys.
- Values never in errors, only service/field names (`cfg.RedactedServices()`).

## Troubleshooting

<details>
<summary>`Secrets()` prefix error at startup</summary>

`prefix` empty or with `/`, `..`, space, set `SECRETS_PREFIX` to e.g. `ZEVER`.
</details>

<details>
<summary>`Get` misses an exported variable</summary>

Exact `<PREFIX>_<NAME>` lookup, case included, `DEMO_KEY` needs `ZEVER_DEMO_KEY` with `ZEVER`.
</details>

<details>
<summary>`Set` always fails</summary>

That is the `env` contract (read-only). Store the value in the environment/process manager, or switch to `vault`.
</details>
