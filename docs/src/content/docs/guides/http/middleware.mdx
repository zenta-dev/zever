Build plain HTTP middleware and gRPC unary interceptors over resolved services (`log`, `ratelimit`, `observability`), no registry or adapter. Construct once while wiring.

## Quick start

No config block (only [CORS](../cors/) takes `Options`), configure the wrapped services:

```sh
```

Defaults from `config.Default()` need no external services. Options: [Config reference](../../../reference/config/#ratelimit).

```go title="main.go" check
package main

import (
    "fmt"
    "net/http"
    "time"

    logslog "github.com/zenta-dev/zever/adapters/log/slog"
    observabilitystdout "github.com/zenta-dev/zever/adapters/observability/stdout"
    ratelimitmemory "github.com/zenta-dev/zever/adapters/ratelimit/memory"
    "github.com/zenta-dev/zever/config"
    "github.com/zenta-dev/zever/container"
    "github.com/zenta-dev/zever/core/log"
    "github.com/zenta-dev/zever/core/middleware"
    "github.com/zenta-dev/zever/core/observability"
    "github.com/zenta-dev/zever/core/ratelimit"
)

func main() {
    c := container.New(config.Default(),
        container.Provide(log.DefaultRef(), func(o log.Options) (log.Logger, error) { return logslog.New(o), nil }),
        container.Provide(ratelimit.DefaultRef(), ratelimitmemory.New),
        container.Provide(observability.DefaultRef(), observabilitystdout.New),
    )
    logger, _ := c.Log()
    limiter, _ := c.RateLimit()
    obs, _ := c.Observability()

    mux := http.NewServeMux()
    mux.HandleFunc("/hello", func(w http.ResponseWriter, r *http.Request) {
        fmt.Fprint(w, `{"ok":true}`)
    })

    handler := middleware.CORS(middleware.Options{
        AllowedOrigins: []string{"https://example.com"},
        AllowedMethods: []string{"GET", "POST", "PUT", "PATCH", "DELETE"},
        AllowedHeaders: []string{"Content-Type", "Authorization"},
        MaxAge:         10 * time.Minute,
    })(middleware.RequestLogger(logger)(
        middleware.Tracing(obs)(
            middleware.RateLimit(limiter, middleware.RemoteAddrKey)(
                middleware.Recover(logger)(mux))))) 

    _ = http.ListenAndServe(":8080", handler)
}
```

```sh
curl -s localhost:8080/hello
```

```text
{"ok":true}
```

Accessors resolve lazily and cache (failed calls retry), `c.Close(ctx)` closes only underlying services. See [the container](../../../concepts/container/).

## Order the chain

Wrap outside in:

1. `CORS` outermost, preflights short-circuit logging and rate limiting.
2. `RequestLogger` next, so recovered panics still log 500.
3. `Recover` innermost, catching panics from inner middleware too.

`Timeout` sits inside `Recover` and outside `RateLimit`, denied requests skip the timer.

## Constructors

| Constructor | Behavior |
|---|---|
| `RequestLogger(logger)` | One line per request with method, path, status, and `duration_ms` as fractional milliseconds in float form, plus `request_id` when present. |
| `Recover(logger)` | Recovers panics (logs value/stack, responds 500), logs only committed handlers. |
| `RateLimit(limiter, keyFunc, opts...)` | Denies with 429 JSON and `Retry-After` (ceiled seconds), key defaults to `RemoteAddrKey`. |
| `Tracing(provider)` | Span per request named by path (`http.request.method`, `url.path`, `http.response.status_code` on completion, error on 5xx), `http.request` counter tagged by method/status. |
| `Timeout(d)` | Bounds handlers to `d` and cancels context, responds 504 with the standard envelope. |
| `CORS(opts)` | Strict cross-origin headers. See [CORS](../cors/). |

The reused recorder exposes `Unwrap`, so `http.ResponseController` still reaches `Flush`/`Hijack`.

### Tracing attributes

Both tracing constructors emit OpenTelemetry semantic-convention names (`http.request.method`, `url.path`, `http.response.status_code`, gRPC: `rpc.system`, `rpc.service`, `rpc.method`, `rpc.grpc.status_code`). Pre-migration names were removed, not aliased, so old-attribute queries return nothing. [Cross-Service Tracing](../../operate/cross-service-tracing/) maps old to new.

Limiter errors fail open by default. Pass `middleware.WithFailMode(middleware.FailClosed)` on sensitive endpoints to answer 429 instead.

## Timeouts

```go
handler := middleware.Timeout(5 * time.Second)(mux)
```

Thread `r.Context()` through every DB, cache, and queue call.

## gRPC interceptors

| HTTP | gRPC | Mapping |
|---|---|---|
| `Recover` | `RecoverUnaryServerInterceptor` | Panic becomes `Internal`. |
| `RateLimit` | `RateLimitUnaryServerInterceptor` | Deny becomes `ResourceExhausted` via `PeerAddrKey`. |
| `Tracing` | `TracingUnaryServerInterceptor` | Span per `FullMethod` (`rpc.system`/`rpc.service`/`rpc.method`/`rpc.grpc.status_code`), `rpc.request` counter by `rpc.service`/`rpc.method`/`rpc.grpc.status_code`. |
| `Timeout` | `TimeoutUnaryServerInterceptor` | Caps handlers at `d`. |

No CORS twin (no gRPC preflight), put recovery last so interceptors see recovered state.

## Checklist

- Set server `ReadHeaderTimeout` (5s), `ReadTimeout` (15s), and `WriteTimeout` (15s), plus per-route `Timeout` for slow endpoints.
- Never log headers, bodies, or option maps, display config via `config.RedactedServices`.
- Alert on limiter errors.

## Troubleshooting

<details>
<summary>Panics return empty 200s</summary>

`Recover` is missing or ordered wrong, keep it closest to the mux.
</details>

<details>
<summary>429s during a Redis outage</summary>

Limiter errors fail open, so steady 429s mean real quota exhaustion, raise rate/burst or narrow the key.
</details>

<details>
<summary>SSE or hijacked connections break</summary>

Custom wrappers hide the writer, forward `Unwrap` for `Flush`/`Hijack`.
</details>

<details>
<summary>Traces are missing</summary>

The provider is probably `noop`, wire `stdout` (or OTLP) and check for path-named spans with `http.response.status_code`.
</details>

<details>
<summary>Timeouts ignored</summary>

Thread `r.Context()` into every downstream call.
</details>
