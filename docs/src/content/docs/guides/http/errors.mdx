Errors are typed values with stable codes, handlers match, map, and log once (see [Logging](../../operate/logging/)). No config block or accessor, `config.Default()` returns production-identical values.

## Quick start

Match with `errors.Is`, write a stable message, log only unexpected branches:

```go title="handlers.go"
func showUser(w http.ResponseWriter, r *http.Request) {
    user, err := findUser(r.Context(), id)
    if errors.Is(err, db.ErrNotFound) {
        writeError(w, http.StatusNotFound, "user not found")
        return
    }
    if err != nil {
        logger.Error().Err(err).Msg("find user failed")
        writeError(w, http.StatusInternalServerError, "internal error")
        return
    }
    writeJSON(w, http.StatusOK, user)
}
```

```sh
curl -s localhost:8080/v1/users/missing -w "\n%{http_code}\n"
```

```text
{"error":"user not found"}
404
```

Log once at the boundary, libraries add `%w` context, handlers choose the status (`writeJSON`/`writeError`: [Requests and responses](../requests-responses/)). Helpers returning `true` skip the generic 500. ORM failures carry `orm:` and `orm/render:` prefixes, the DSL mirrors `apperror` codes in `ir.ErrorCode`.

`.zen` RPCs declare their error set (`errors: { already_exists }`) for clients and OpenAPI.

## Status map

| Error | Status | Envelope |
|---|---|---|
| `db.ErrNotFound` | 404 | `{"error":"user not found"}` |
| `dialect.ErrUnsupportedByDialect` | 400 | `{"error":"query not supported by this database"}` |
| RPC `already_exists` | 409 | `{"error":"already exists"}` |
| Rate-limit deny | 429 plus `Retry-After` | `{"error":"rate limit exceeded"}` |
| Handler timeout (`middleware.Timeout`) | 504 | `{"error":"request timed out"}` |
| Handler panic (`middleware.Recover`) | 500 | `{"error":"internal error"}` |
| Anything else | 500 | `{"error":"internal error"}` |

Also: 400 unparsable, 422 invalid ([Validation](../validation/)).

## Shutdown errors

`c.Close(ctx)` returns an `errors.Join` of per-service errors, match `container.ClosePanicError` and `container.CloseTimeoutError` (value types) with `errors.As`, then log the joined error once at exit:

```go
var pe container.ClosePanicError
if errors.As(err, &pe) { /* a service panicked during Close */ }
```

## Redact secrets

Name services and fields, never values, same for logs and config display (`zever config show` prints redacted config, render via `config.RedactedServices`).

## Troubleshooting

<details>
<summary>`errors.Is(err, db.ErrNotFound)` never matches</summary>

A layer broke the chain (`%v` or a new error), wrap with `%w` everywhere.
</details>

<details>
<summary>A 500 body leaks internals</summary>

The handler leaks `err.Error()`, write a stable slug and log the detail.
</details>

<details>
<summary>Dialect failure misleads</summary>

Postgres-only features return `dialect.ErrUnsupportedByDialect` by design, match it and use a portable formulation.
</details>

<details>
<summary>Opaque shutdown error</summary>

You print only the first error, log the full joined value, then `errors.As` for panic and timeout cases.
</details>
