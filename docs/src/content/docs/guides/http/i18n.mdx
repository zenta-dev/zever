Localize every visible string per locale: embed the catalog for development, pull from a remote service in production. Never concatenate translated fragments, translators need full sentences with placeholders.

## Quick start

```sh
I18N_EMBED_DIR=locales
I18N_EMBED_FALLBACK=en
```

The default wiring embeds the catalog (`i18nembed.New` in `internal/app/wiring.go`), `remote` is a wiring change, not an env key.

Switch to `remote` for shared catalogs:

```sh
I18N_REMOTE_ENDPOINT=https://i18n.internal:8080
```

The `remote` adapter takes `endpoint`, `api_key`, `timeout`, `max_in_flight`, `allow_insecure`, and `allow_private` (see the [Config reference](../../../reference/config/#i18n)). Outbound requests dial only globally routable addresses and never follow redirects, a local sidecar needs `allow_private: true` (logged at startup). `DefaultTimeout` is 30s. Set `Embed.FS` in code (env cannot provide filesystems), without it the embed adapter fails with `embed fs is required`.

Catalogs are JSON per locale, messages are plain text or `text/template` strings with placeholders:

```json title="locales/en.json"
{"welcome": "Welcome back!", "hello": "Hello, {{.name}}!"}
```

```json title="locales/fr.json"
{"hello": "Bonjour, {{.name}}!"}
```

```go title="main.go"
import (
    "embed"

    i18nembed "github.com/zenta-dev/zever/adapters/i18n/embed"
    "github.com/zenta-dev/zever/config"
    "github.com/zenta-dev/zever/container"
    "github.com/zenta-dev/zever/core/i18n"
)

//go:embed locales/*.json
var localesFS embed.FS

cfg := config.Default()
cfg.I18n.Options.Embed = i18n.EmbedOptions{FS: localesFS, Dir: "locales", Fallback: "en"}
c := container.New(cfg, container.Provide(i18n.DefaultRef(), i18nembed.New))
t, _ := c.I18n()

msg, _ := t.Translate(ctx, "fr", "hello", map[string]string{"name": "Ada"})
fmt.Println(msg)
missing, _ := t.Translate(ctx, "fr", "welcome", nil)
fmt.Println(missing)
```

```text
Bonjour, Ada!
Welcome back!
```

Missing keys fall back through the chain, exhausted keys return `i18n.KeyNotFoundError`, never empty. Templates use `missingkey=error`, so missing arguments fail loudly. `I18n()` is lazy and cached, `c.Close(ctx)` shuts it down.

## Resolve the locale

Resolve user preference, then `Accept-Language`, then the configured default, in one helper or middleware.

```go
func localeOf(r *http.Request, user *User) string {
    if user != nil && user.Locale != "" {
        return user.Locale
    }
    if h := r.Header.Get("Accept-Language"); h != "" {
        return parsePrimary(h) // "fr-CA,fr;q=0.9" -> "fr-CA"
    }
    return "en"
}
```

Lookup falls back `fr-CA` to `fr` to the default (`i18n.BaseLocale`, `i18n.LocaleChain`). Pass structured args (`map[string]string`), word order differs across languages.

## API

The interface has `Translate(ctx, locale, key, args)` and `Locales(ctx)`, `i18n.Open(adapter, opts)` and `i18n.Register(adapter, factory)` bypass the container. `EmbedOptions{FS, Dir, Fallback}` and `RemoteOptions{Endpoint, APIKey, Timeout, MaxInFlight, AllowInsecure}` configure each side, `Options.Validate()` rejects bad settings at startup. Treat catalogs as data: version with the schema, diff in review, deploy beside the binary or behind the remote endpoint.

## Test fallbacks

Assert fallbacks, not copy (copy changes without review), test with embed using a missing key.

## Checklist

- Always set `fallback` to your source locale.
- Pass `r.Context()` and cache hot keys in front of `remote`.
- Options can carry credentials, display config only through `config.RedactedServices`.

## Troubleshooting

<details>
<summary>Blanks in one locale</summary>

No `fallback`, or the helper returns empty, set `fallback` and test.
</details>

<details>
<summary>Wrong language served</summary>

Resolution points disagree, centralize `localeOf` and log at debug level.
</details>

<details>
<summary>Remote catalog hangs requests</summary>

Pass `r.Context()` to `Translate` and bound the timeout.
</details>
