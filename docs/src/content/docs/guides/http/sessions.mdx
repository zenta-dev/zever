A session is a server-side row: the browser holds an opaque cookie ID, the server holds the data. Sessions cover revocable browser flows (logout, password reset, privilege change), `auth` tokens suit APIs and service-to-service calls.

## Quick start

```sh
SESSION_REDIS_ADDR=redis:6379
```

Wire `redis` in `internal/app/wiring.go` for production (shared across instances), default is in-process `memory`.

`config.Default()` resolves `memory`, zero TTL means `DefaultTTL` (15 minutes) and negative TTLs fail `Options.Validate()`. `db` takes `dsn` and `dedicated_pool` (shares the container pool per DSN by default), `redis` takes `redis.prefix` plus the shared Redis connection keys. All options: [Config reference](../../../reference/config/#session).

Create, save, read:

```go title="session.go"
import (
    "context"
    "net/http"

    "github.com/zenta-dev/zever/adapters/session/cookie"
    "github.com/zenta-dev/zever/core/session"
)

// At startup: c := container.New(config.Default(), container.Provide(session.DefaultRef(), sessionmemory.New)); store, _ := c.Session()

func login(ctx context.Context, store session.Store, w http.ResponseWriter) error {
    sess, _ := store.Create(ctx, session.DefaultTTL)
    sess.Data["user_id"] = "u_123"
    _ = store.Save(ctx, sess)
    cookie.Set(w, sess.ID, cookie.Options{})
    return nil
}

func loadSession(ctx context.Context, store session.Store, r *http.Request) (session.Session, error) {
    c, err := r.Cookie(cookie.DefaultName)
    if err != nil {
        return session.Session{}, err
    }
    return store.Get(ctx, c.Value)
}
```

```sh
curl -s -i -X POST localhost:8080/login | head -8
```

```text
HTTP/1.1 200 OK
Set-Cookie: session_id=<opaque-id>; Path=/; HttpOnly; Secure; SameSite=Lax
```

`Session()` is lazy and cached. `Get` returns `session.ErrNotFound` for missing or expired sessions (indistinguishable by design). `Session.Data` is a plain `map[string]any`, keep it to IDs and flags, since every request loads the row. `ttl <= 0` means no expiry.

## Session cookie

`session.Store` is HTTP-free, `cookie.New(sess.ID, opts)` builds a plain `*http.Cookie`, `cookie.Set(w, id, opts)` writes it.

| Attribute | Default |
|---|---|
| Name, Path | Defaults `cookie.DefaultName` (`session_id`) and `cookie.DefaultPath` (`/`), `Options.Name`/`Options.Path` override. |
| `Domain` | Unset (host-only), set it to widen to subdomains. |
| `Prefix` | None. `cookie.PrefixHost` (`__Host-`) forces Secure, `Path=/`, no Domain. `cookie.PrefixSecure` (`__Secure-`) forces Secure. |
| Secure flags | `HttpOnly`/`Secure` default `true` (HTTPS only), `SameSite` defaults `Lax` (`http.SameSiteStrictMode` for high-risk apps). |
| `MaxAge` | `0` is a session cookie, negative deletes, positive sets `Max-Age`/`Expires`. |

`Secure`/`HttpOnly` are `*bool`, so explicit `false` (local HTTP dev) differs from unset. Rotate IDs at privilege changes (login, password reset) against fixation, `Delete` the old row, then `Create` anew.

## CSRF defense

The browser attaches `session_id` to every request, including cross-site `POST`s from attacker forms or `fetch`. `SameSite=Lax` (the default) stops most of it, but top-level `GET` navigations still carry the cookie, older browsers ignore `SameSite`, widened `Domain` exposes sibling subdomains, and `SameSite=None` opts out. Layer accordingly:

1. Keep `Lax`, use `http.SameSiteStrictMode` for high-risk apps (it also blocks top-level login links).
2. Set `Prefix` to `cookie.PrefixHost` (`__Host-`) for single-host apps, browsers refuse cookies unless `Secure`, `Path=/`, host-only.
3. Never change state on `GET` (CSRF needs ambient credentials, reads have nothing to steal).
4. Verify `Origin` (fallback `Referer`) against an explicit allowlist on every state-changing handler, `403` on missing or untrusted values. A cross-site form cannot forge `Origin` since the browser sets it, so a mismatch proves the request came from elsewhere.
5. When `SameSite=None` is required or subdomains are hostile, add a synchronizer token: mint a random per-session value, render it into forms (or expose it to your frontend over an authenticated endpoint), require it back in a header or field, and compare with `subtle.ConstantTimeCompare`. No framework CSRF middleware exists, own the check in your app.
6. For pure APIs, prefer `Authorization`-header tokens (`auth` `jwt`/`oidc`) over cookies, no ambient credentials, no CSRF surface.

```go title="csrf.go"
import (
    "crypto/subtle"
    "net/http"
    "strings"
)

// allowOrigin reports whether origin is this app's own site. Compare
// against an explicit allowlist, never against the request Host. The
// Host header is attacker-controlled on most deployments.
func allowOrigin(origin string) bool {
    return origin == "https://app.example.com"
}

func requireSameOrigin(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        if origin := r.Header.Get("Origin"); origin != "" {
            if !allowOrigin(origin) {
                http.Error(w, "forbidden", http.StatusForbidden)
                return
            }
        } else if referer := r.Header.Get("Referer"); referer != "" {
            if !strings.HasPrefix(referer, "https://app.example.com/") {
                http.Error(w, "forbidden", http.StatusForbidden)
                return
            }
        } else {
            // No Origin and no Referer. A browser same-origin POST always
            // sends one of them, so fail closed rather than assume safe.
            http.Error(w, "forbidden", http.StatusForbidden)
            return
        }
        next.ServeHTTP(w, r)
    })
}

func checkToken(submitted, expected string) bool {
    return subtle.ConstantTimeCompare([]byte(submitted), []byte(expected)) == 1
}
```

## Store API

| Method | Purpose |
|---|---|
| `Create(ctx, ttl)` | Mint a session (`ttl <= 0` never expires). |
| `Get(ctx, id)` | Load by ID, `ErrNotFound` on missing or expired. |
| `Save(ctx, sess)` | Upsert the row, touching `UpdatedAt`. |
| `Delete(ctx, id)` | Remove the row, idempotent (use for logout). |

Helpers: `session.NewSession(id, ttl)`, `Session.Clone()`, `Session.Expired(now)`, `session.Open(adapter, opts)`, `session.Register(adapter, factory)`. `auth` (`jwt`, `oidc`) is stateless, `session` is revocable, `authz` verifies via `auth` and decides via `permission`.

## Checklist

- Multi-instance requires `redis`, `memory` pins users to one process.
- Stores are `Close()`-shaped, shared redis clients close once, all via `c.Close(ctx)`.
- Log IDs and chosen fields, never whole `Session.Data`.
- Pass `r.Context()` into `Create`/`Get`/`Save`, set explicit TTLs (short for sensitive flows).

## Troubleshooting

<details>
<summary>Local login works, production drops</summary>

Instances run `memory`, wire `redis` plus a shared `SESSION_REDIS_ADDR`.
</details>

<details>
<summary>Missing cookies on local HTTP</summary>

`Secure` defaults true, browsers drop it over HTTP, so set explicit `false` for dev.
</details>

<details>
<summary>`Get` returns `ErrNotFound` right after `Create`</summary>

`Save` was skipped or the cookie holds the wrong ID, `Save` after mutating `Data`, and set the cookie from `sess.ID`.
</details>
