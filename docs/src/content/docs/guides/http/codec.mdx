Serialize typed values to bytes for `cache`, `queue`, `session`, and webhooks, write custom codecs only when JSON is wrong.

## Quick start

No YAML, env, or container accessor (no `c.Codec()`), construct it directly:

```go title="main.go" check
package main

import (
    "fmt"

    "github.com/zenta-dev/zever/shared/codec"
)

type MyPayload struct {
    ID   string `json:"id"`
    Name string `json:"name"`
}

func main() {
    c := codec.JSONCodec[MyPayload]{}

    data, _ := c.Encode(MyPayload{ID: "u_1", Name: "Ada"})
    back, _ := c.Decode(data)
    fmt.Printf("%s %s\n", back.ID, back.Name)
}
```

```text
u_1 Ada
```

Only `JSONCodec[V]` ships, with deterministic output for snapshots and byte assertions. Codecs do no I/O and hold no connections, share them. Interfaces: `Encoder[V]` (`Encode`), `Decoder[V]` (`Decode`), `Codec[V]` (both), `cache.NewTyped` applies one to cache `Get`/`Set`.

## Store typed values

Resolve the byte store, then wrap it:

```go
// imports: config, container, cachememory ("github.com/zenta-dev/zever/adapters/cache/memory"),
//   "github.com/zenta-dev/zever/core/cache", "github.com/zenta-dev/zever/shared/codec"
c := container.New(config.Default(), container.Provide(cache.DefaultRef(), cachememory.New))
inner, _ := c.Cache()
typed := cache.NewTyped[string, MyPayload](inner, codec.JSONCodec[MyPayload]{})

typed.Set(ctx, "user:u_1", MyPayload{ID: "u_1", Name: "Ada"}, time.Minute)
got, _ := typed.Get(ctx, "user:u_1")
fmt.Println(got.Name)
```

```text
Ada
```

One `Codec[V]` per stored type, shared by writer and reader, queue and session paths share the shape (resolve with `c.Queue()` and `c.Session()`).

## Custom codecs

Implement `Codec[V]` for other formats:

```go
type gobCodec[V any] struct{}

func (gobCodec[V]) Encode(v V) ([]byte, error) { /* ... */ }
func (gobCodec[V]) Decode(data []byte) (V, error) { /* ... */ }

var _ codec.Codec[MyPayload] = gobCodec[MyPayload]{}
```

Keep `Encode`/`Decode` symmetric, `JSONCodec` ignores unknown fields and defaults missing ones.

## Checklist

- Never log encoded bytes, log IDs/sizes.
- Keep payloads small.
- Use `JSONCodec` for snapshots and hashes.

## JSON engine

All JSON goes through `shared/codec` (`encoding/json/v2`, Go 1.27): import the facade, never the engine. Defaults are deterministic key order and Duration strings (`"30s"`, as env parses). `UnmarshalStrict` fails closed on unknown fields, `MarshalIndentCompat` is for stable stamp output only.

## Troubleshooting

<details>
<summary>Added field breaks decode</summary>

Added keys default fine, a changed type is the culprit. Keep JSON types stable or version the wrapper.
</details>

<details>
<summary>Cache reads return zero values</summary>

Different codecs on writer and reader, build both from one `Codec[V]`.
</details>

<details>
<summary>Snapshot tests flap</summary>

Use `JSONCodec`, or sort keys in `Encode`.
</details>
