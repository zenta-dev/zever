Strict cross-origin HTTP middleware for browser calls, requests without `Origin` pass through.

## Wire CORS

No `cors` config section: decode your app's block into `middleware.Options` (snake_case `json` tags), `r.Use` outermost before any `Handle`:

```yaml
cors:
  allowed_origins: ["https://example.com"]
  allowed_methods: ["GET", "POST", "PUT", "PATCH", "DELETE"]
  allowed_headers: ["Content-Type", "Authorization"]
  exposed_headers: ["X-Request-Id"]
  allow_credentials: true
  max_age: 10m
```

```go title="main.go"
import (
    "time"

    "github.com/zenta-dev/zever/core/middleware"
)

handler := middleware.CORS(middleware.Options{
    AllowedOrigins:   []string{"https://example.com"},
    AllowedMethods:   []string{"GET", "POST", "PUT", "PATCH", "DELETE"},
    AllowedHeaders:   []string{"Content-Type", "Authorization"},
    ExposedHeaders:   []string{"X-Request-Id"},
    AllowCredentials: true,
    MaxAge:           10 * time.Minute,
})(mux)
```

`MaxAge` is a `time.Duration` in delay-seconds (`10m` becomes `600`).

## Responses

| Request | Response |
|---|---|
| No `Origin` | Passes through, no CORS headers. |
| Allowed origin, simple | Handler runs. `Allow-Origin` echoes origin, `Vary: Origin`. |
| Allowed preflight match | `204` with `Allow-Origin`, `Allow-Methods`, `Allow-Headers`, `Max-Age`. |
| Allowed preflight mismatch | `403`, no `Allow-Origin`. |
| Disallowed origin | Never reflected, simple passes, preflights fall through. |

## Validate

`Options.Validate` rejects fail-open shapes (empty origin/method lists, blank entries, `*` with `AllowCredentials`, negative `MaxAge`), invalid options fail closed with `500 {"error":"internal error"}`. A credentialless `*` echoes `*` for any origin. `DefaultCORSMaxAge` (`0`) omits `Max-Age`, so browsers preflight every request.

Keep `CORS` outermost (preflights skip logging and rate limiting), call `r.Use` before `Handle` (`stdhttp` snapshots middleware per route). HTTP-only ([chain order](../middleware/#order-the-chain)).

## Troubleshooting

<details>
<summary>Logged or rate-limited preflights</summary>

Move `CORS` outermost.
</details>

<details>
<summary>Browser blocks a valid origin</summary>

Allowlist mismatch, add the exact origin.
</details>

<details>
<summary>Unexpected preflight 403</summary>

Method or header outside the allowlist (matching is case-insensitive), add it.
</details>

<details>
<summary>All CORS requests 500</summary>

`Options` is invalid, often `*` with credentials.
</details>
