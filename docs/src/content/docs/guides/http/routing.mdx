`router` serves hand-written or `.zen` RPC routes on `fiber`/`stdhttp`, `zever routes` prints the table. `stdhttp` (default) is conversion-free `net/http.ServeMux`, `fiber` adds `fasthttpadaptor` (~46 vs ~17 allocs/op, [Benchmarks](../../../reference/benchmarks/#router-re-measurement-2026-10-14-and-stdhttp-default)) for `stdhttp` gaps (case-sensitive `:name` params).

## Register

Switch drivers (one per process): `container.Provide(Router, routerfiber.New)`. `c.Router()` is lazy and cached, no `Close`. Options: [Config reference](../../../reference/config/#router).

```go title="main.go" check
package main

import (
    "fmt"
    "net/http"

    routerstdhttp "github.com/zenta-dev/zever/adapters/router/stdhttp"
    "github.com/zenta-dev/zever/config"
    "github.com/zenta-dev/zever/container"
    "github.com/zenta-dev/zever/core/router"
)

func main() {
    c := container.New(config.Default(), container.Provide(router.DefaultRef(), routerstdhttp.New))
    r, _ := c.Router()

    r.Handle("GET", "/users/{id}", func(w http.ResponseWriter, req *http.Request) {
        fmt.Fprintf(w, "user %s", router.Param(req, "id"))
    })

    _ = http.ListenAndServe(":8080", r)
}
```

```sh
curl -s localhost:8080/users/42
# user 42
```


## Patterns

| Pattern | `fiber` | `stdhttp` |
|---|---|---|
| `/users/:id` | `:id` | rejected |
| `/users/{id}` | `:id` | `{id}` |
| `/files/{path...}` | `*` wildcard | `{path...}` |
| `/users/{$}` | literal | `{$}` exact |
| `/items/:id<[0-9]+>` | passthrough | rejected |

## API

| Method | Purpose |
|---|---|
| `Handle(method, pattern, handler)` | Register |
| `Group(prefix, middlewares...)` | Scope |
| `Use(middlewares...)` | Append |
| `router.Param(req, name)` | Read |
| `router.ParamNames(req)` | Read params |
| `router.WithParams(ctx, params)` | Inject |
| `router.ValidMethod(method)` | Validate |
| `router.Open(adapter, opts)` | Open |
| `router.Register(adapter, factory)` | Add driver |

`router.ValidMethod` accepts: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, `OPTIONS`, `CONNECT`, `TRACE`, the rest log `[router]` and skip. Registering the same method and pattern twice logs `[router]` and keeps the first handler. `Handle` takes `http.HandlerFunc` on both drivers, so handler code stays unchanged when switching drivers. Generated servers set `ReadHeaderTimeout`, `ReadTimeout`, `WriteTimeout`, and `IdleTimeout` on `http.Server`. On `stdhttp`, `Use` covers only later routes. Shut down `http.Server` gracefully with timeouts, display config via `config.RedactedServices`.

## Troubleshooting

<details>
<summary>404s on <code>stdhttp</code>, not <code>fiber</code></summary>

Rewrite as `{id}`.
</details>

<details>
<summary><code>Use</code> ignored on <code>stdhttp</code></summary>

Move `Use` before `Handle`.
</details>
