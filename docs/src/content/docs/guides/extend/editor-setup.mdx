## Install

The [one-line installer](../../../start/installation/) puts `zever-lsp` beside `zever` (Neovim 0.11+/VS Code). Open the workspace root.

```sh
curl -fsSL https://raw.githubusercontent.com/zenta-dev/zever/main/install.sh | sh
# or, from a local clone:
go install ./tools/zever-lsp
```

No config/flags. Stdio only. Version in `initialize` `serverInfo`.

## Agents (MCP)

`tools/zever-mcp` is a stdio [MCP](https://modelcontextprotocol.io) server letting Claude Code, Cursor, and other clients validate/inspect schemas without shelling out. Separate from editor LSP. No config.

```sh
go build -o zever-mcp ./tools/zever-mcp
```

```json title=".mcp.json"
{ "mcpServers": { "zever": { "command": "/path/to/zever-mcp" } } }
```

Tools take `dir`/`files`: `zever_check` (`ok`/`file:line:col`), `zever_routes` (routes JSON), `zever_schema`/`zever_explain` (summaries), `zever_compile` (merged OpenAPI). `zever_doctor`/`zever_generate` shell to `zever` on `PATH`. `zever_generate` needs dry-run plan plus approval. Table: [AI](../../integrations/ai/#give-coding-agents-the-compiler-over-mcp).

## Connect editor

<Tabs>
  <TabItem label="Neovim">
Load `editors/nvim` (filetypes/highlighting):

```lua
{
  'zenta-dev/zever',
  config = function(plugin)
    vim.opt.rtp:append(plugin.dir .. '/editors/nvim')
  end,
}
```

LSP registration is manual:

```lua
vim.lsp.config('zever-lsp', {
  cmd = { 'zever-lsp' },
  filetypes = { 'zen' },
  root_markers = { '.git' },
})
vim.lsp.enable('zever-lsp')
```

Optional format on save:

```lua
vim.api.nvim_create_autocmd('BufWritePre', {
  pattern = '*.zen',
  callback = function(args)
    vim.lsp.buf.format({ bufnr = args.buf, timeout_ms = 2000 })
  end,
})
```
  </TabItem>
  <TabItem label="VS Code">
Install `editors/vscode`. Keep `zever-lsp` on `$PATH` (client only) with `editor.formatOnSave` for `zen`.
  </TabItem>
</Tabs>

Verify with an unknown scalar: confirm the diagnostic appears (`:lua vim.diagnostic.open_float()`/Problems), then clears.

## CLI loop

```sh
zever fmt --write schema/*.zen
zever check schema/*.zen
```

| Command | Purpose |
|---|---|
| `zever fmt --write <files...>` | Format in place (list changes without `--write`). |
| `zever check <files...>` | Report diagnostics. |
| `zever compile --out ./generated <files...>` | Generate backend output. |
| `zever check-boundaries <files...>` | Report cross-module violations (relations, RPC return types, permission resources). |
| `zever tinker` | Dev-only Go REPL (stderr warning). Never production data. |

Commands: [CLI reference](../../../reference/cli/).

## Regenerate grammars

After touching `token.Keywords`/`resolver.ScalarTypeNames`, run `make generate` (`tools/gengrammar` renders `editors/nvim`+`editors/vscode`). `editors/parity_test.go` diffs them, skipping fails the build.

## Server support

| Area | Methods |
|---|---|
| Sync | `didOpen`, `didChange` (full), `didSave`, `didClose`, `didChangeWatchedFiles` |
| Diagnostics | `publishDiagnostics` (debounced. Empty when clean) |
| Symbols | `documentSymbol`, `workspace/symbol` |
| Navigation | `definition`, `references`, `documentHighlight`, `foldingRange` |
| Completion/hover | `completion` (`@`, `:`, space), `completionItem/resolve`, `hover`, `signatureHelp` (`(`, `,`) |
| Editing | `formatting`, `rangeFormatting`, `codeAction` (unknown scalars, relation targets) |
| Rename | `prepareRename`, `rename` (entities, fields, jobs, services, RPCs) |
| Semantic tokens | `semanticTokens/full` |
| Inlay hints | `inlayHint` + resolve (implicit module, `errors:` cases) |

In-process compiler-resolver compilation keeps editor/build in agreement. Lockstep `tools/zever-lsp/vX.Y.Z`.

## Troubleshooting

<details>
<summary>`zever-lsp: command not found`</summary>

Off `PATH`: re-run `go install`, add `$(go env GOPATH)/bin`.
</details>

<details>
<summary>No diagnostics</summary>

Detached client/wrong root: check `:LspInfo`/Output, reopen at `initialize` root.
</details>

<details>
<summary>Garbled responses</summary>

Server-stdout writes: drop stream-merging wrappers. Logs to stderr.
</details>

<details>
<summary>Grammar drift</summary>

Skipped `make generate`: run it and commit.
</details>
