The Zever skill teaches coding agents CLI use (scaffolding, inspection, runtime) and machine interfaces (`--json`, `--help --agent`, MCP). Humans read the [CLI reference](../../../reference/cli/) instead.

## Install

Generate the skill from any pinned `zever` binary:

```sh
zever docs --skill --dir ~/.claude/skills/zever
```

Writes `SKILL.md` (frontmatter, workflows, catalog). Snapshot at `skills/zever/SKILL.md`. `skill_test.go` pins output: regenerate after command changes via `zever docs --skill --dir skills/zever`.

## Contents

- Triggers: scaffold, add battery, check/compile schema, run server.
- Machine interfaces: `--json` envelopes, `--help --agent` catalog, `tools/zever-mcp` server.
- Workflows: scaffold-and-run, add-a-battery, inspect-a-schema (`--dry-run` first).
- Safety: preview mutations. `tinker` dev-only. Secrets out of logs.
