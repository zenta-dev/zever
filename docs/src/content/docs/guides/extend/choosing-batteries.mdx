Switch adapters via imports and `container.Provide` in `internal/app/wiring.go`, not config.

`config.Default()` is zero-infra (`memory`, `local`, `sqlite`, `log`, `noop`) for tests/`zever serve`. See [adapters matrix](../../../reference/adapters-matrix/).

## Rule

Single process: `memory`/`sqlite`. Shared state: `redis`/`postgres` (`db` reuses the existing DB, or substitutes without Redis, at the cost of polling and database load). Money, auth, or compliance: never `stub`, `noop`, or `memory` (`stub` payment and billing verify nothing and hold no funds). Verify with `zever doctor` after rewiring.

## Choices

| Battery | Local/tests | Production | Notes |
| --- | --- | --- | --- |
| `db` | `sqlite` | `postgres` (multi-instance/write-heavy) | `sqlite` `:memory:` per connection. File under `t.TempDir()`. |
| `cache` | `memory` | `redis` (shared). `db` w/o Redis | `memory` not shared across replicas. |
| `queue` | `memory` | `redis` workers. `db` w/o Redis | Only `redis`/`db` cross-host. See [Queue](../../background/queue/). |
| `session` | `memory` | `redis` or `db` | Survives restarts/replicas. |
| `auth` | `jwt` | `jwt`. `session` cookies. `oidc` IdP tokens | `jwt` needs >=32-byte secret. |
| `ratelimit` | `memory` | `redis` across replicas | |
| `lock`, `idempotency` | `memory` | `redis` or `db` | Cross-instance correctness. |
| `eventbus` | `memory` | `redis` fan-out | No offline-handler durability. |
| `outbox` | `memory` | `db`. `cdc` for Postgres | Defaults to `db`. |
| `scheduler` | `embedded` | `postgres` durable leased slots | |
| `observability` | `stdout` | `otlp` collector | `noop` for tests. |
| `log` | `slog`/`pretty` | `slog`/`zerolog` JSON. `noop` tests | |
| `storage` | `local` | `s3`/`r2` | |
| `search`, `vectorstore` | `db` | `meilisearch`/`qdrant` at scale | Start on `db`. |
| `secrets` | `env` | `vault` rotation/audit | `env` needs restart. |
| `permission` | `noop` | `rbac`/`casbin` | |
| `router` | `stdhttp` | `stdhttp`/`fiber` | Match middleware needs. |

## Wire

`zever add` writes imports + `container.Provide` in `internal/app/wiring.go`:

```sh
zever add cache/redis
zever doctor
```

Unwired batteries fail at startup (`NotWiredError`). Trim via `zever build --adapters` ([CLI reference](../../../reference/cli/)).
