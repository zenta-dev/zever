Typed per-request feature flags. Missing keys return the fallback with nil error. Full how-to: [Feature flags guide](../../guides/operate/flags/).

## Adapters

| Adapter | Module | Constructor | Wired default |
|---|---|---|---|
| `static` | `github.com/zenta-dev/zever/adapters/flag/static` | `static.New` | Yes |
| `firebase` | `github.com/zenta-dev/zever/adapters/flag/firebase` | `firebase.New` | No |

Resolve via `c.Flag()`. Swap backends via `container.Provide` and rebuild.

## Configuration

Service key: `flag`. Example:

```sh
FLAG_STATIC_PATH=flags.json
FLAG_STATIC_RELOAD=true
```

Env rule: `FLAG_<FIELD>=value`, uppercase, no prefix. Non-empty `options` replace defaults wholesale. Env vars overlay one field at a time. Layering: [Config reference](../config/).

## Options

Options nest under the adapter name. Types and defaults: [Config reference](../config/#flag).

| Key | Type | Default | Notes |
|---|---|---|---|
| `static.path` | string | `""` | Flag file path, empty means an empty flag set |
| `static.reload` | boolean | `false` | Enables file reloading |
| `firebase.project_id` | string | `""` | Firebase project ID (required by the adapter) |
| `firebase.service_account` | string | `""` | Path to the service account JSON key file (required by the adapter) |
| `firebase.timeout` | duration | `30s` | Operation timeout, zero means the default, negative fails validation |

Keys must be 1..256 bytes with no control chars or `DEL` (`ValidateKey`).

## Errors

Package-level `ErrXxx` in `core/flag` (`errors.go`). Branch with `errors.Is`.

| Sentinel | Cause | Fix |
|---|---|---|
| `ErrClosed` | Client used after `Close` | Open a new client, do not reuse the closed one |
| `ErrNilFactory` | registry gone (compat) | Unused: `New` takes no factory |
| `ErrDuplicateAdapter` | duplicate wiring (compat) | Wire each Ref once. Duplicates fail at `container.New` with `DuplicateRefError` |
| `ErrDuplicate` | Alias of `ErrDuplicateAdapter` | Same |
| `ErrUnknownAdapter` | registry gone (compat) | Backends chosen by import with `container.Provide` (e.g. `static.New`), never parsed from a name |
| `ErrInvalidAdapter` | `ParseAdapter` gone (compat) | Backends chosen by import, never parsed from a name |
| `ErrInvalidOptions` | `Options.Validate` failed (for example negative `firebase.timeout`) | Keep `firebase.timeout >= 0`, adapters validate their own required fields |
| `ErrInvalidKey` | Flag key empty, over 256 bytes, or containing control characters | Fix the key, the error carries the key length only, never the key itself |

A missing flag key returns the caller fallback, not an error.
