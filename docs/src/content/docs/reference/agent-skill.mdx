## Purpose

The Zever skill teaches coding agents the CLI surface: scaffolding,
inspection, and runtime commands plus the machine interfaces (`--json`,
`--help --agent`, MCP). Use it when an agent works in a Zever project;
humans should read the [CLI Reference](cli/) instead.

## Install

Generate and install the skill from any pinned `zever` binary:

```sh
zever docs --skill --dir ~/.claude/skills/zever
```

This writes a single `SKILL.md` (frontmatter plus workflows plus the live
command catalog). The committed snapshot lives at `skills/zever/SKILL.md`;
`skill_test.go` pins the generator output against it, so regenerate the
snapshot after changing commands with `zever docs --skill --dir skills/zever`.

## Contents

- When-to-use trigger phrases (scaffold app, add battery, check schema,
  compile schemas, run server).
- Machine interfaces: `--json` envelopes, `--help --agent` catalog, and
  the `tools/zever-mcp` MCP server.
- Workflows: scaffold-and-run, add-a-battery, inspect-a-schema, each with
  `--dry-run` first.
- Safety: preview mutations, `tinker` is development-only, secrets stay out
  of logs.
