## Purpose

One interface per top-level package, self-registering adapters, container as
sole resolver. This matrix maps service to adapter packages and accessors so
swaps stay config-only.

## Notes

- `New(nil)` is valid; untouched services close cleanly without opening.
- Accessors resolve lazily and retry on next call after an error.
- `Job()` builds over resolved `Queue`; `Scheduler()` shares both.
- `Close(ctx)` closes only resolved services, dependents first.
- Don't add methods to public interfaces; prefer new interfaces.
