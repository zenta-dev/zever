Batteries live in `core/<b>` (`Options`, `DefaultRef`). Adapters in `adapters/<b>/<a>` (`New`, wired via `container.Provide`). Helpers in `shared/*`. Import `core` plus adapters, resolve via `container`. `dsl/*` is internal-only.

## Construct and resolve

Construction is config plus container. Services resolve on first use and cache. Errors clear the cache for retry.

```go
import (
    "github.com/zenta-dev/zever/config"
    "github.com/zenta-dev/zever/container"
)

c := container.New(config.Default())
db, err := c.DB()
if err != nil {
    return err
}
q, err := c.Queue()
if err != nil {
    return err
}
d, err := c.Job() // d shares the resolved queue instance
if err != nil {
    return err
}
```

`container.New(nil)` is valid: untouched containers close without opening. `Job()` builds a `*job.Dispatcher` over `Queue` (no registry). `Scheduler()` injects it, sharing `Queue`. Resolving `Scheduler()` resolves `Job()` and `Queue`.

`GRPCClient(target, opts...)` builds `*grpc.ClientConn` via `shared/grpcclient` (round-robin LB, retry, TLS, static resolver), one cached conn per target, closed with the container.

## Close

```go
ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
defer cancel()
if err := c.Close(ctx); err != nil {
    var te *container.CloseTimeoutError
    var pe *container.ClosePanicError
    _ = te
    _ = pe
    return err
}
```

Close shuts down only resolved services, dependents first, joining failures via `errors.Join`.

## Close shapes

| Shape | Used by | Semantics |
|---|---|---|
| `Close(ctx)` | pooled or network-backed services that may block (`db`, `cache`, `storage`, `lock`, `container` itself) | context-bounded shutdown |
| `Close()` | lightweight handles, iterators, statements, instant-close in-memory adapters (`auth`, `queue`, `session`, `payment`, `eventbus.Pusher`, `ratelimit.Limiter`, `db.Rows`, `db.Stmt`) | instant close |
| `Stop()` | scheduler only | cron lifecycle stop |

Probing (`closeAny`) tries `Close(ctx)`, `Close()`, `Stop()`, `Shutdown(ctx)` (observability flush), then no-op. `*job.Dispatcher` has no shutdown method, and neither do crypto, log, password, permission, or router. The probe picks the shape.

Close order:

```text
scheduler, job        dependents holding a queue ref, first
snapshots             everything without explicit ordering
cache, queue          leaf dependencies, last
db, registry pools    shared pools, after every borrower (no use-after-close)
grpcServer            independent GracefulStop/Stop, bounded by ctx
grpc clients          independent, one conn per target, closed with the container
```

Per-service bound is 5s only when the parent has no deadline, else the parent bounds each wait. Shared instances close once (pointer-identity dedup with a `keepAlive` set for the duration of Close). Failures join via `errors.Join`, panics become `*ClosePanicError`, timeouts `*CloseTimeoutError`. Errors name the service only, never resolved values. `Close` never opens anything.

## Production notes

- Start from `config.Default()` + `container.New`, then per-service accessors. No globals, no `init()`.
- Keep to documented interfaces. New behavior means new interfaces, never new methods.
- Pass a parent deadline to `Close` so shutdown is bounded end to end. Inspect `CloseTimeoutError` / `ClosePanicError` with `errors.As`.
- Document exit paths on goroutine-safe types. Resolve the in-memory subset and `Close` it in tests for clean `goleak`.

## Troubleshooting

- **Close hangs**: parent has no deadline and a service blocks. Pass a timeout context (5s bound applies only without one).
- **Close reports `CloseTimeoutError`**: a service outlived its bound. Check the named service and its store.
- **Close reports `ClosePanicError`**: a service panicked during shutdown. The value is captured, not re-thrown.
- **Accessor keeps failing**: each call retries fresh, so persistent failure is config or backend. Check `Validate` and connectivity.
