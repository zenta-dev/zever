Server-side sessions with TTL expiry. Expired sessions read as missing. Not a cookie jar. After login call `Rotate` against fixation. Full how-to: [Sessions guide](../../guides/http/sessions/).

## Adapters

| Adapter | Module | Constructor | Wired default |
|---|---|---|---|
| `memory` | `github.com/zenta-dev/zever/adapters/session/memory` | `memory.New` | Yes |
| `redis` | `github.com/zenta-dev/zever/adapters/session/redis` | `redis.New` | No |
| `db` | `github.com/zenta-dev/zever/adapters/session/db` | `db.New` | No |

Resolve via `c.Session()`. `memory` is local-only, use a shared store beyond dev. `session/cookie` is a stdlib cookie helper. Swap backends via `container.Provide` and rebuild.

## Configuration

Service key: `session`. File example:

```sh
SESSION_TTL=15m
SESSION_REDIS_ADDR=localhost:6379
```

Env rule: `SESSION_<FIELD>=value`, uppercase, no prefix. Non-empty `options` replace defaults wholesale. Env vars overlay one field at a time. Layering: [Config reference](../config/).

## Options

Authority: [Config reference](../config/#session).

| Key | Type | Default | Notes |
|---|---|---|---|
| `ttl` | duration | `15m` | Default session lifetime, zero means the default, negative fails |
| `dsn` | string | `""` | Postgres connection string or sqlite path for the db adapter, empty selects a private in-memory database |
| `dedicated_pool` | boolean | `false` | Opts out of container-level pool sharing, default shares one pool per exact DSN |
| `redis.prefix` | string | `""` | Key prefix for Redis session data |
| `redis.url` | string | `""` | Reserved and currently ignored |

Plus shared `redis.*` keys (`addr`, `password`, `db`, `tls`, pooling): [Redis connection options](../config/#redis-connection-options).

Session IDs are 256-bit bearer secrets (64 hex chars). Never log them. `ValidateID` rejects malformed IDs without revealing them.

## Errors

Package-level `ErrXxx` in `core/session` (`errors.go`). Branch with `errors.Is`.

| Sentinel | Cause | Fix |
|---|---|---|
| `ErrNotFound` | Session does not exist or has expired (expired reads as missing) | Treat as logged-out: start a new session |
| `ErrClosed` | Store used after `Close` | Open a new store, do not reuse the closed one |
| `ErrNilFactory` | kept for compatibility, the registry is gone | Unused: `New` takes no factory |
| `ErrDuplicateAdapter` | kept for compatibility, duplicate wiring is a duplicate `Provide` for one Ref | Wire each Ref once, duplicates fail at `container.New` with `DuplicateRefError` |
| `ErrDuplicate` | Alias of `ErrDuplicateAdapter` | Same as above |
| `ErrUnknownAdapter` | kept for compatibility, the registry is gone | Backends are chosen by import with `container.Provide` (for example `memory.New`), never parsed from a name |
| `ErrInvalidAdapter` | kept for compatibility, `ParseAdapter` is gone | Backends are chosen by import, never parsed from a name |
| `ErrInvalidOptions` | `Options.Validate` failed (negative `ttl`, bad Redis address or prefix) | Fix the named field |
| `ErrInvalidID` | Malformed session ID | Reject the request, the error carries the ID length only, never the ID |
