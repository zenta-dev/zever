Token-bucket limiting via `Limiter`. `Decision` carries `Allowed`, `RetryAfter`, `Remaining`. Not HTTP middleware: map denials to 429 and choose fail-open on error. Full how-to: [Ratelimit guide](../../guides/security/ratelimit/).

## Adapters

| Adapter | Module | Constructor | Wired default |
|---|---|---|---|
| `memory` | `github.com/zenta-dev/zever/adapters/ratelimit/memory` | `memory.New` | Yes |
| `redis` | `github.com/zenta-dev/zever/adapters/ratelimit/redis` | `redis.New` | No |

Resolve via `c.RateLimit()`. Use `redis` across replicas, `memory` is per-instance. Swap backends via `container.Provide` and rebuild.

## Configuration

Service key: `ratelimit`. `rate` and `burst` are required. File example:

```sh
RATELIMIT_RATE=100
RATELIMIT_BURST=200
```

Env rule: `RATELIMIT_<FIELD>=value`, uppercase, no prefix. Non-empty `options` replace defaults wholesale, so repeat `rate` and `burst`. Env vars overlay one field at a time. Layering: [Config reference](../config/).

## Options

Authority: [Config reference](../config/#ratelimit).

| Key | Type | Default | Notes |
|---|---|---|---|
| `rate` | number | `10` (config default) | Token refill rate per second, must be > 0 and finite |
| `burst` | integer | `20` (config default) | Maximum bucket size, must be > 0 |
| `idle_ttl` | duration | `10m` | Idle entry TTL, zero means the adapter default, negative fails |
| `sweep_interval` | duration | `1m` | Idle-entry sweep interval, zero means the adapter default, negative fails |
| `max_entries` | integer | `1000` | Bucket-table bound in the memory adapter before LRU eviction, non-positive means the default |
| `trusted_proxies` | list of string | `[]` | CIDRs (or bare IPs) of proxies whose `X-Forwarded-For` headers are honored, empty trusts none |
| `redis.prefix` | string | `""` | Key prefix for Redis ratelimit data |
| `redis.url` | string | `""` | Reserved and currently ignored |

Plus shared `redis.*` keys (`addr`, `password`, `db`, `tls`, pooling): [Redis connection options](../config/#redis-connection-options).

Keys must be 1..256 bytes with no control chars (`ValidateKey`). Key errors carry length only, since keys may be IPs. Costs must be positive and finite (`ValidateCost`). Cost above burst is capped.

## Errors

Package-level `ErrXxx` in `core/ratelimit` (`errors.go`). Branch with `errors.Is`.

| Sentinel | Cause | Fix |
|---|---|---|
| `ErrClosed` | Limiter used after close | Open a new limiter, do not reuse the closed one |
| `ErrNilFactory` | kept for compatibility, the registry is gone | Unused: `New` takes no factory |
| `ErrDuplicateAdapter` | kept for compatibility, duplicate wiring is a duplicate `Provide` for one Ref | Wire each Ref once, duplicates fail at `container.New` with `DuplicateRefError` |
| `ErrDuplicate` | Alias of `ErrDuplicateAdapter` | Same as above |
| `ErrUnknownAdapter` | kept for compatibility, the registry is gone | Backends are chosen by import with `container.Provide` (for example `memory.New`), never parsed from a name |
| `ErrInvalidAdapter` | kept for compatibility, `ParseAdapter` is gone | Backends are chosen by import, never parsed from a name |
| `ErrInvalidOptions` | `Options.Validate` failed (bad `rate`/`burst`, negative TTLs, bad Redis address or prefix, bad `trusted_proxies` entry) | Fix the named field, blank or unparsable proxy entries name the entry |
| `ErrInvalidKey` | Rate-limit key empty, over 256 bytes, or containing control characters | Fix the key, the error carries the length only, never the key |
| `ErrInvalidCost` | Token cost or burst not > 0 or not finite | Pass a positive finite cost |
