title: Errors and Logging
description: Typed errors with gRPC codes, HTTP mappings, and secret-safe structured logging.

Errors are typed values with stable codes; logs are structured lines with redacted secrets. Handlers map one to the other: match the error, pick the status, log once.

## Typed errors

`apperror` defines the shared vocabulary with gRPC codes and HTTP mappings, mirrored by the DSL's `ir.ErrorCode` table:

```go
if errors.Is(err, db.ErrNotFound) {
    writeError(w, http.StatusNotFound, "user not found")
    return
}
```

| Pattern | Use |
|---|---|
| sentinel + `errors.Is` | stable branches (`db.ErrNotFound`, `dialect.ErrUnsupportedByDialect`) |
| `%w` wrapping | add context without losing identity |
| `errors.As` for `*ClosePanicError` / `*CloseTimeoutError` | shutdown diagnostics |
| `orm:` / `orm/render:` prefixes | ORM failures stay greppable and compatible |

`.zen` RPCs declare their error set (`errors: { already_exists }`), so generated OpenAPI and clients know which codes to expect. The `breaking` checker treats error-set changes as API changes.

## Logging

Resolve one logger and inject it — middleware constructors take it as an argument:

```go
logger, err := c.Log()
if err != nil {
    return err
}
handler := middleware.RequestLogger(logger)(mux)
```

| Adapter | Config | Output |
|---|---|---|
| `noop` | default (silent) | nothing |
| `slog` | `log: {adapter: slog}` | stdlib structured lines |
| `zerolog` | `log: {adapter: zerolog}` | high-throughput JSON |

`RequestLogger` emits one line per request (method, path, status, `duration_ms`, plus `request_id` when present). `Recover` logs panics with value + stack and responds 500 `{"error":"internal error"}`.

## The redaction rule

Raw option maps may hold secrets as plain strings. Never log them directly:

```go
// Wrong: may print DSNs, API keys, JWT secrets.
log.Info("config", "cfg", cfg)

// Right: sole display path for logging or debugging.
fmt.Println(config.RedactedServices(cfg))
```

Error text names services and fields only — values are never echoed. The CLI follows the same rule (`zever config show` prints redacted config; migrate screens mask `--dsn ***`).

Panics in handlers become 500s via `Recover`; panics during `Close` become `*ClosePanicError` in the joined shutdown error. Log the shutdown error once at exit — it already aggregates every service.
