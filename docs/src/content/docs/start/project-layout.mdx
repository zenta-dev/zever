Monorepo (`go 1.27.3`). Import `core`, adapters, `container/`, never `dsl/`.

## Roles

```text
core/<b>          battery interface + Options + DefaultRef (container resolves)
adapters/<b>/<a>  one Go module per adapter; New constructor wired with container.Provide
shared/*          SDK-free helpers (codec, redisclient, s3opts, retry, ...)
wiring            config/ container/    layered config + lazy resolver
language          dsl/                  .zen compiler frontend (compile time only)
surface           orm/ cmd/zever/       typed queries, CLI
```

- `go.work`: 181 `use` (`examples/external-sms`, `docs/examples` outside). Root `go build/test ./...`. CI `GOWORK=off`.
- Lockstep: one version, per-module tags `<path>/vX.Y.Z` (`tools/tag-release.sh`).
- `config/`: env in. `container/`: build, cache, retry, close.

## Resolve a service

`container/` alone resolves: name constructors in `container.Provide`, called lazily on first use:

```go title="main.go" check
package main

import (
	"fmt"

	dbsqlite "github.com/zenta-dev/zever/adapters/db/sqlite"
	"github.com/zenta-dev/zever/config"
	"github.com/zenta-dev/zever/container"
	"github.com/zenta-dev/zever/core/db"
)

func main() {
	c := container.New(config.Default(), container.Provide(db.DefaultRef(), dbsqlite.New))
	db, err := c.DB()
	if err != nil {
		panic(err)
	}
	fmt.Println("db resolved:", db != nil)
}
```

Output:

```text
db: sqlite
```

Dialect via `conn.Dialect()` per call. Same code prints `postgres`.

## Conventions

- No globals/`init()`. `ctx` first for IO, never stored.
- Exports need leading-name doc. `goimports` prefix `github.com/zenta-dev/zever`. `depguard` denies `github.com/pkg/errors`, `io/ioutil`.
- No new methods on public interfaces. New interface instead.
- New service: `core/<b>` interface/`Options`/`DefaultRef` + `adapters/<b>/<a>` module (`New` via `container.Provide`) + `shared/*` code + `README.md` table.
- `time.Duration` for timeouts/intervals (cookie `MaxAge` excepted). `MaxConn*` pools. Snake_case `json` on JSON options.
- Deterministic tests (no `time.Sleep`/network/unseeded rand). Suffixes: `cover`, `live`, `bench`, `internal`, `race`, `closure`. Helpers: `stub*`, `must*`, `freshAdapter`.
- One container/process. Dependency-order close with timeout ([Lifecycle](../../concepts/lifecycle/)).

## Troubleshooting

<details>
<summary>Service package imports `dsl`</summary>

Remove import. Consume output. See [compiler boundary](../../concepts/compiler-boundary/).
</details>

<details>
<summary>New interface method breaks adapters</summary>

Revert method. Add a new interface.
</details>

<details>
<summary>`go build ./...` passes, docs site fails</summary>

`docs/` is npm: `npm run dev` under `docs/`, Node 22.12+.
</details>

<details>
<summary>New service lacks adapter table</summary>

Add interface, dirs, registration, `README.md` table.
</details>
