## How it fits together

<Steps>

1. **Describe** entities and services in a `.zen` schema ([syntax](../../reference/zen-syntax/)).
2. **Compile** with `zever compile` into typed ORM, OpenAPI, and migration DDL ([backends](../../concepts/backends/)).
3. **Wire** services through one lazy `container.Container` ([container](../../concepts/container/)).
4. **Swap** adapters (sqlite to postgres, memory to redis) by editing config, never call sites ([adapters](../../concepts/providers-adapters/)).

</Steps>
