## Install

One command installs the CLI and language server. No sudo is needed because the default prefix is `~/.local/bin`:

```sh
curl -fsSL https://raw.githubusercontent.com/zenta-dev/zever/main/install.sh | sh
```

Windows: `irm https://raw.githubusercontent.com/zenta-dev/zever/main/install.ps1 | iex`. See [installation](../installation/).

## Flow

<Steps>
1. **Describe** entities/services in `.zen` ([syntax](../../reference/zen-syntax/)).
2. **Compile** via `zever compile` ([backends](../../concepts/backends/)).
3. **Wire** via `container.Container` ([container](../../concepts/container/)).
4. **Swap** adapters via config ([adapters](../../concepts/providers-adapters/)).
</Steps>
