`main` trunk, Conventional Commits, `make check` gate. Docs in `docs/` (Astro/Starlight).

## Setup

Go 1.27, pinned tools (`golangci-lint` v2.15.0, `govulncheck` v1.8.0, `cyclonedx-gomod` v1.12.0):

```sh
make setup
```

```sh
git clone git@github.com:zenta-dev/zever.git
cd zever
make download
make test
```

`make test-race` adds race detection. `make help` lists targets.

## Preview docs

```sh
cd docs
npm install
npm run dev
```

Preview at `http://localhost:4321`. `npm run build` builds the site, `npm run preview` serves it. Check edited pages before a PR.

## Workflow

Branch from `main`, open a draft PR, merge after review, CI, approval.

## Conventional Commits

```text
<type>: <short description>
```

```text
feat: add schema compiler
fix: prevent resolver panic
perf: reduce lexer allocations
refactor: simplify container wiring
test: add parser regression tests
docs: improve adapter documentation
ci: test against Go 1.27
build: update dependencies
```

Subject completes "This change will ...". Keep commits focused. User-facing changes need a `CHANGELOG.md` entry under `## [Unreleased]`.

## Check gate

```sh
make check
```

`make check` runs, in order: `require-tools`, `download`, `fmt`, `check-all` (per module: `go vet`, `go mod tidy -diff`, `go test -vet=off`, `go build`), `check-tags`, `err-lint`, `modgraph-check`, `dependabot-check`, `lint-all`, `vulncheck-all`, `installer-test`, `changelog-compile-test`, `changelog-compile-check`, `sbom-test`, `compile-check`, `version-check`, `changelog-lint`. It has no race target. CI runs `test-race-fast` on PRs, so pair `make check` with `make test-race-fast` locally.

```sh
make fmt / make fmt-fix     # gofmt check / write
make lint / make lint-fix   # golangci-lint (config .golangci.yml)
make vet                    # go vet ./...
make vulncheck              # govulncheck ./...
make tidy-check             # go mod tidy -diff
make err-lint               # error-convention scan (tools/errscan)
make generate               # go run ./tools/gengrammar (after touching token.Keywords or resolver.ScalarTypeNames)
```

CI runs `make check-all`. PRs run `make test-race-fast` (race, no coverage). Coverage (`make test-race-all`) and benchmarks stay on main and tag pushes. Run `make test-race-fast` before pushing.

## Coding standards

- Idiomatic Go, formatted with `make fmt-fix`. Name-first comments on exports.
- No globals, no `init()` wiring. `ctx` first for IO, never stored.
- Wrap errors with `%w`. `depguard` denies `github.com/pkg/errors` and `io/ioutil`.
- Small interfaces. Never extend public ones, add one.
- Deterministic tests: no `time.Sleep` sync, network, unseeded randomness, or timing assertions. `t.Fatal` for setup, `t.Error` for table assertions, `t.Helper`, `t.Context()`.
- Maintainer review for public API changes.

## Writing conventions

See the [docs style guide](./writing-docs/): one page type (tutorial, guide, concept, reference), answer first, runnable snippets, keys and commands verified in code.

## Troubleshooting

- `make lint` fails on untouched files: `make setup` pins golangci-lint v2.15.0. Other installs differ.
- `make tidy-check` fails: tidy each touched module. Committed `go.work` for local dev. `GOWORK=off` for per-module CI.
- Blank preview: re-run `npm install` in `docs/`. The terminal error names the broken file.
