## How it fits together

<Steps>

1. **Describe** entities and services in a `.zen` schema ([syntax](../../dsl/syntax-zen/)).
2. **Compile** with `zever compile` into typed ORM, OpenAPI, and migration DDL ([backends](../../dsl/backends/)).
3. **Wire** services through one lazy `container.Container` ([container](../../architecture/container/)).
4. **Swap** adapters (sqlite to postgres, memory to redis) by editing config, never call sites ([adapters](../../architecture/providers-adapters/)).

</Steps>
